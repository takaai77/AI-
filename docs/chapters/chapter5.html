トークンとは何か
進捗0%
💰 CURRENCY

AIの「通貨」を理解する

トークンはAIの世界における「通貨」のようなものです。プロンプトを書くとき、出力を受け取るとき、すべてトークン単位で計算されます。コスト管理にも直結する重要な概念です。

🪙
QUICK RULE
英語: 1トークン ≈ 4文字 or 0.75単語
日本語: 1トークン ≈ 1〜2文字
📚 TERMINOLOGY
🪙
トークン
Token
テキストを処理するための最小単位。単語、サブワード、文字など言語によって異なる。AIモデルはトークン単位で入力を受け取り、出力を生成する。API利用料金もトークン数で計算される。
📏
トークン制限（Token Limit）
Token Limit / Max Tokens
一度のリクエストで処理できるトークンの最大数。入力（プロンプト）と出力（生成テキスト）の合計。GPT-4では8K〜128Kトークン、GPT-5では更に拡大。制限を超えると切り捨てられる。
🔡
BPE（Byte Pair Encoding）
Byte Pair Encoding
GPTで使われるトークン化アルゴリズム。頻出する文字の組み合わせを1つのトークンとして扱う。「the」は1トークン、「extraordinary」は複数トークンに分割される。
📊 EXAMPLES

トークン化の例

Token Examples
# 英語の例 "Hello world" → ["Hello", " world"] = 2 tokens "ChatGPT is amazing" → ["Chat", "GPT", " is", " amazing"] = 4 tokens # 日本語の例 "こんにちは" → ["こん", "にち", "は"] = 3 tokens "プログラミング" → ["プログ", "ラミ", "ング"] = 3 tokens # コードの例 "function test() {}" → 6 tokens
⚠️ 日本語は要注意

日本語は英語より多くのトークンを消費します。同じ意味でも日本語は2〜3倍のトークン数になることも。コスト意識が必要です。

💡 PRACTICAL

なぜトークンが重要？

💰 ビジネスへの影響
1
コスト
API利用料金は「入力トークン数 + 出力トークン数」で計算
2
速度
トークン数が多いほど処理時間が長くなる
3
品質
制限内でいかに必要な情報を伝えるかが鍵
💡 節約テクニック
  • 冗長な表現を避ける
  • 例示は最小限に（2-3個）
  • 不要な説明を削除
  • 英語でプロンプトを書く（可能なら）
🎯 KNOWLEDGE CHECK

日本語と英語、同じ意味の文章ではどちらがトークン消費が多い？

A 日本語の方が多い
B 英語の方が多い
C 同じ
D 時と場合による
解説: 日本語はBPEトークン化では効率が悪く、同じ意味の文章でも英語の2〜3倍のトークンを消費することがあります。APIコストを意識する場合は重要なポイントです。

🔑
KEY TAKEAWAYS

  • ✅ 日本語は英語より多くトークン消費
  • ✅ 簡潔なプロンプトがコスト効率◎
