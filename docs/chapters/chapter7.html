APIの基礎知識

このチャプターでは、APIの基礎知識について深く学んでいきます。 実践的な知識とスキルを身につけ、Codexマスターへの道を進みましょう。

📚 TERMINOLOGY
🔌
API
Application Programming Interface
異なるソフトウェア間でデータをやり取りするための仕組み。Codex APIを使えば、自分のアプリからCodexの機能を呼び出せる。
🎯
エンドポイント
Endpoint
APIにリクエストを送る特定のURL。例: /v1/chat/completions
↔️
リクエスト/レスポンス
Request/Response
APIとの通信の基本形式。リクエスト（要求）を送り、レスポンス（応答）を受け取る。
🔑
APIキー
API Key
APIにアクセスするための認証情報。秘密に保管し、コードにハードコードしてはいけない。
🎯 KNOWLEDGE CHECK

APIキーの取り扱いで正しいものは？

A GitHubに公開する
B コードに直接書く
C 環境変数で管理する
D SNSで共有する
解説: 正解は選択肢Cです。このチャプターの内容をしっかり復習しましょう。
