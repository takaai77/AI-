コンテキストウィンドウ

このチャプターでは、コンテキストウィンドウについて深く学んでいきます。 実践的な知識とスキルを身につけ、Codexマスターへの道を進みましょう。

📚 TERMINOLOGY
📦
コンテキストウィンドウ
Context Window
AIモデルが一度に処理できるトークンの最大範囲。この「窓」の中にある情報だけをモデルは参照できる。GPT-4は8K〜128K、GPT-5は更に大きなコンテキストに対応。
📏
コンテキスト長
Context Length
現在の会話やプロンプトで使用しているトークン数。長すぎると古い情報が切り捨てられる可能性がある。
📜
ロングコンテキスト
Long Context
非常に長いテキスト（書籍全体、大規模コードベースなど）を処理する能力。最新モデルでは100K以上のトークンに対応。
