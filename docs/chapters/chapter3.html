プロンプトの基本概念

📖 CORE CONCEPT

プロンプトとは何か？

プロンプト（Prompt）は、AIに対するあなたの「指示」です。料理で言えばレシピ、建築で言えば設計図。プロンプトの質が、出力の質を決定します。

💡
GOLDEN RULE
良いプロンプト = 良い出力
曖昧なプロンプト = 曖昧な出力
🔬 ANATOMY

プロンプトの構成要素

📋 5つの基本要素
1
タスク（Task）
何をしてほしいか。「関数を作成して」「このコードを説明して」など
2
コンテキスト（Context）
背景情報。「Reactプロジェクトで」「初心者向けに」など
3
制約（Constraints）
条件や制限。「TypeScriptで」「100行以内で」など
4
例示（Examples）
入出力の例。「入力: [1,2,3] → 出力: 6」など
5
フォーマット（Format）
出力形式の指定。「JSON形式で」「コメント付きで」など
📚 TERMINOLOGY
💬
プロンプト
Prompt
AIモデルに与える入力テキスト。指示、質問、コンテキストなどを含む。モデルはこれを読み取り、適切な応答を生成する。プロンプトの書き方を最適化する技術を「プロンプトエンジニアリング」と呼ぶ。
🎯
プロンプトエンジニアリング
Prompt Engineering
AIから最適な出力を得るためにプロンプトを設計・最適化する技術。2020年代に登場した新しい専門分野で、AIを効果的に活用するための必須スキル。
📝
インストラクション
Instruction
プロンプト内でAIに与える具体的な命令部分。「以下のコードをリファクタリングしてください」のように、明確なアクションを指示する。
⚖️ COMPARISON

悪いプロンプト vs 良いプロンプト

❌ BAD PROMPT
"ソート関数作って" # 問題点: # - 何をソートする？（数値？文字列？オブジェクト？） # - どの言語？ # - 昇順？降順？ # - アルゴリズムの指定は？
✅ GOOD PROMPT
""" TypeScriptで数値配列を降順にソートする関数を作成してください。 要件: - 関数名: sortDescending - 引数: numbers: number[] - 戻り値: number[]（ソート済み配列） - 元の配列を変更しない（イミュータブル） 例: 入力: [3, 1, 4, 1, 5] 出力: [5, 4, 3, 1, 1] """
💡 違いのポイント
  • 言語指定: TypeScript
  • 具体的な仕様: 関数名、引数、戻り値
  • 制約: イミュータブル
  • 例示: 入出力の具体例
📐 FRAMEWORK

5W1Hフレームワーク

プロンプトを書く際は、以下の質問に答えられるか確認しましょう：

❓ 6つの質問
W
What（何を） - 何を作成/修正/説明してほしいか
W
Why（なぜ） - 目的や背景は何か
W
Who（誰が） - 対象ユーザーは誰か
W
Where（どこで） - どの環境/フレームワークで使うか
W
When（いつ） - どのタイミングで実行されるか
H
How（どのように） - 具体的な方法/アルゴリズムは
🎮 TRY IT: プロンプト改善

「ログイン機能を作って」という曖昧なプロンプトを、5つの基本要素を使って改善してみましょう。

🎯 KNOWLEDGE CHECK

プロンプトの5つの基本要素に含まれないのは？

A タスク（Task）
B コンテキスト（Context）
C パスワード（Password）
D 例示（Examples）
解説: プロンプトの5つの基本要素は「タスク」「コンテキスト」「制約」「例示」「フォーマット」です。パスワードはプロンプトの要素ではありません（むしろプロンプトに含めるべきでない機密情報です）。
🎯 KNOWLEDGE CHECK

「ソート関数作って」というプロンプトの最大の問題点は？

A 日本語で書かれている
B 具体性が欠けている
C 文字数が少ない
D 敬語を使っていない
解説: 問題は「具体性の欠如」です。言語、データ型、ソート順、アルゴリズムなどが指定されていないため、AIは最適な出力を生成できません。プロンプトは日本語でも英語でも問題なく、文字数より内容の具体性が重要です。
✍️ OUTPUT: 5要素を使う

「メール送信機能を作って」というタスクについて、5つの基本要素（タスク、コンテキスト、制約、例示、フォーマット）を使って詳細なプロンプトを書いてみましょう。

🔑
KEY TAKEAWAYS
  • ✅ プロンプト = AIへの指示書
  • ✅ 5要素: タスク/コンテキスト/制約/例示/フォーマット
  • ✅ 曖昧さは敵、具体性が味方
  • ✅ 5W1Hで漏れをチェック
