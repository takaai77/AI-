# Ops Automation Memory Page

非エンジニア向けに、以下を語呂と比喩で学ぶためのページです。

- 内部API
- Cloud Tasks
- Worker (Playwright)
- BigQueryログ

## 公開URL

このリポジトリの GitHub Pages では次のURLになります。

`https://<your-account>.github.io/<repo-name>/ops-automation-memory/`

## デプロイ

既存の `deploy-quiz-pages.yml` が `quiz-site/**` の変更をデプロイするため、
このディレクトリをコミットして `main` か `master` に push すれば公開されます。

手動実行する場合は GitHub Actions の `Deploy Quiz Site to GitHub Pages` を `Run workflow` します。
