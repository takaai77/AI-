# Quiz Site

GitHub Pages向けの静的学習コンテンツです。

## 含まれる内容
- 実装優先度ロードマップ
- 用語カード（定義 / たとえ話 / このプロジェクト例）
- 用語検索（スマホで素早く復習）
- セキュリティ運用チェックリスト
- セキュリティ中心クイズ / 全範囲クイズ
- 弱点復習モード（前回の誤答領域を重点出題）
- インシデント対応モード（初動・封じ込め・再発防止）
- 今日のチャレンジ（同日同問題の固定出題）
- 学習ダッシュボード（直近成績と次の推奨学習）
- 管理者問題追加画面（JSON直編集なし、ローカル保存）
- カスタム問題のエクスポート / インポート
- PWA対応（インストール・オフライン学習）

## ローカル確認
```bash
cd quiz-site
python -m http.server 8080
```
`http://localhost:8080` を開く

## 管理者機能
- `管理者: 問題を追加` セクションから問題を追加
- 追加問題はこの端末の `localStorage` に保存
- `エクスポート` で JSON 保存、`インポート` で他端末へ移行可能

## PWA機能
- 対応ブラウザでは「アプリとしてインストール」ボタンが表示されます
- 一度アクセスすると、主要アセットはキャッシュされオフライン時も学習継続できます
- オフライン時は画面上部のネットワーク表示が切り替わります
