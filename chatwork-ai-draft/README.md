# Chatwork AI返信下書きサポート Chrome拡張

Chatwork Web版のメッセージ入力欄の近くに「AI返信」ボタンを表示し、
AIが返信の下書きを作成するChrome拡張機能です。

**重要: この拡張機能は送信を自動で行いません。下書きの作成のみを行います。**
送信ボタンを押すのは必ず人間です。

## 概要

- Chatwork Web版でのみ動作
- LINEのAI返信のような軽量UIで下書きを提案
- n8n Webhook → Gemini API（またはVertex AI）で文面を生成
- 入力欄に「挿入」するだけ。送信は行わない
- 個人情報の簡易マスク機能付き
- カスタムプロンプトで自社ルール・文体を指定可能
- 返信テンプレートで定型的な返信をワンクリックで生成

## セットアップ手順

### 前提条件

- Google Chrome ブラウザ（バージョン 116 以降推奨）
- n8n（またはWebhookを受けられる中継サーバー）
- Gemini API キー（n8n側で設定。拡張内には保持しない）

### 1. リポジトリの取得

```bash
git clone <このリポジトリのURL>
```

### 2. Chromeへの読み込み

1. Chromeで `chrome://extensions` を開く
2. 右上の **「デベロッパーモード」** をONにする
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. `chatwork-ai-draft/` フォルダを選択する
5. 拡張機能が読み込まれ、ツールバーにアイコンが表示される

### 3. n8n Webhook の設定

n8n側で以下のようなワークフローを作成してください。

#### リクエスト形式（この拡張から送られるJSON）

```json
{
  "roomName": "配送相談",
  "threadContext": [
    { "speaker": "相手", "text": "発送日は変更できますか？" },
    { "speaker": "自分", "text": "確認いたします。" }
  ],
  "intent": "丁寧に短く返信したい",
  "tone": "polite",
  "retryMode": false,
  "customPrompt": "です・ます調で統一してください。",
  "templateName": "確認・承知"
}
```

> `customPrompt` と `templateName` はオプションフィールドです。
> 設定画面でカスタムプロンプトが設定されている場合、
> またはテンプレートが選択された場合にのみ含まれます。

#### レスポンス形式（n8nが返すべきJSON）

```json
{
  "ok": true,
  "draft": "お問い合わせありがとうございます。発送日変更について確認のうえご案内いたします。",
  "toneLabel": "丁寧",
  "notes": "確定情報がないため断定を避けています。"
}
```

#### tone の値

| 値 | 意味 |
|---|---|
| `neutral` | 通常 |
| `polite` | 丁寧 |
| `soft` | やわらかい |
| `short` | 短い |
| `summary` | 要点のみ |

### 4. 拡張機能の設定（options画面）

1. Chromeの拡張機能アイコンをクリック → 設定画面が開く
2. **Webhook URL** に n8n の Webhook URL を入力
3. **取得メッセージ件数** を設定（推奨: 3〜5件）
4. **カスタムプロンプト** に自社ルールや文体指定を入力（任意）
5. **返信テンプレート** を必要に応じて追加・管理
6. 「設定を保存」をクリック

## Chatwork上での使い方

1. Chatwork Web版 (`https://www.chatwork.com/`) を開く
2. チャットルームを選択する
3. メッセージ入力欄の近くに **「✨ AI返信」ボタン** が表示される
4. ボタンをクリックするとAIカードが開く
5. 以下のいずれかの方法で下書きを生成する:
   - 「どう返信したいですか？」にざっくり意図を入力して「返信を提案」
   - 「📋 テンプレートから選ぶ」でプリセットまたはカスタムテンプレートを選択
6. 下書きプレビューが表示される
7. 必要に応じてトーンを変更（🎩丁寧に / 🌸やわらかく / ✂️短く / 📌要点だけ）
8. **🔄再生成** で別の表現を試す。**↩️元に戻す** で前の下書きに戻せる
9. **📥入力欄に挿入** をクリックすると、Chatworkの入力欄にテキストが入る
10. **内容を確認し、自分で送信ボタンを押す**

## テンプレート機能

### プリセットテンプレート（8種類）

| アイコン | テンプレート名 | 用途 |
|---|---|---|
| 🙏 | お礼の返信 | 感謝を丁寧に伝える |
| ✅ | 確認・承知 | 承知した旨を返信 |
| 🙇 | やんわりお断り | 相手を傷つけずに断る |
| ❓ | 質問・確認依頼 | 不明点を質問 |
| 📅 | 日程調整 | 日程の候補提案・調整 |
| 📊 | 進捗報告 | 作業進捗の簡潔な報告 |
| 💦 | お詫び | 遅延やミスのお詫び |
| 📝 | 依頼・お願い | タスクや対応の依頼 |

### カスタムテンプレートの追加

設定画面の「返信テンプレート管理」セクションから、
自分専用のテンプレートを追加・削除できます。

設定項目:
- **テンプレート名**: カード上に表示される名前
- **AIへの指示**: AIに渡される意図テキスト
- **アイコン**: 絵文字1文字
- **カテゴリ**: グループ分け用ラベル
- **デフォルトトーン**: 選択時に自動設定されるトーン

### カスタムプロンプト

設定画面の「カスタムプロンプト」欄に、AIへの追加指示を設定できます。

例:
- 「返信はです・ます調で統一してください」
- 「社名は「株式会社サンプル」です」
- 「敬語レベルを高めにしてください」
- 「箇条書きを多用してください」

この内容は `customPrompt` フィールドとして n8n に送られます。
n8n のワークフロー内で Gemini API のシステムプロンプトに結合してください。

## セキュリティ方針

詳細は [SECURITY.md](./SECURITY.md) を参照してください。

### 要約

| 方針 | 内容 |
|---|---|
| **APIキー非保持** | Gemini APIキーはn8nサーバー側のみで管理 |
| **データ最小化** | 直近数件のメッセージのみ送信。個人情報は簡易マスク |
| **保存最小化** | localStorage不使用。一時データはメモリ/session storage |
| **ログ最小化** | 会話本文・下書き本文をconsole.logに出力しない |
| **権限最小化** | Chatworkドメインのみに制限。`<all_urls>` 不使用 |
| **送信禁止** | 送信ボタンの自動操作は一切行わない |
| **XSS防止** | innerHTML不使用。textContentベースで表示 |

### 何を永続保存するか / しないか

| データ | 保存先 | 理由 |
|---|---|---|
| Webhook URL | chrome.storage.local | 設定値（機密性低） |
| メッセージ件数 | chrome.storage.local | 設定値 |
| カスタムプロンプト | chrome.storage.local | ユーザー定義の指示文 |
| テンプレート | chrome.storage.local | ユーザー定義の定型パターン |
| 下書き・チャット内容 | **保存しない** | 業務データの永続化を避ける |
| 生成履歴 | **保存しない** | メモリ上の直前1件のみ（元に戻す用） |

## 制限事項

- **DOMセレクタ**: ChatworkのDOM構造が変更されると動作しなくなる可能性がある。
  `lib/dom-selectors.js` と `TODO_SELECTORS.md` を参照して更新してください。
- **個人情報マスク**: 完全ではない。正規表現ベースの簡易マスクのため、
  すべての個人情報を検出できるわけではない。
- **SPA遷移**: Chatworkはシングルページアプリケーションのため、
  ルーム切り替え時にUIの再初期化が必要。MutationObserverで対応しているが、
  稀にボタンが消える場合がある（ページリロードで復帰）。
- **n8n依存**: AI生成はn8n経由のため、n8nがダウンしていると機能しない。
- **テンプレートのエクスポート**: 現時点ではテンプレートのインポート/エクスポート機能はない。

## 本番運用での注意点

1. **n8n の保護**: Webhook の前段に認証レイヤー（社内VPN、IP制限、
   Basic認証、OAuthなど）を設置することを **強く推奨** する。
2. **HTTPS必須**: Webhook URLは必ず HTTPS を使用すること。
3. **Gemini API利用規約**: 業務データをAIに送る場合、
   Gemini/Vertex AI の利用規約を確認すること。
   無料版はデータが学習に使われる可能性がある。Vertex AI（有料）を推奨。
4. **アイコン**: 現在のアイコンはプレースホルダー。
   本番では適切なアイコンに差し替えること。
5. **カスタムプロンプトの運用**: 全社で統一するプロンプトがある場合、
   n8n 側のシステムプロンプトに直接設定する方が管理しやすい。
   拡張側のカスタムプロンプトは個人の微調整用途を想定。
