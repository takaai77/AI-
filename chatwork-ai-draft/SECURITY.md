# セキュリティ方針

このドキュメントでは、「Chatwork AI返信下書きサポート」拡張機能の
セキュリティ設計方針と、その限界について説明します。

## 何を守りたいか

1. **業務チャットの内容** — Chatwork上のメッセージは業務上の機密情報を含む可能性がある
2. **個人情報** — 氏名、メールアドレス、電話番号、住所などの個人を特定できる情報
3. **認証情報** — APIキー、パスワード、トークンなどの秘密情報
4. **利用者のプライバシー** — 誰がどんな内容をAIに問い合わせたかの履歴

## どんな情報を送るか

n8n Webhook に送信するデータは以下に限定しています。

| フィールド | 内容 | 制限 |
|---|---|---|
| `roomName` | チャットルーム名 | マスク処理済み |
| `threadContext` | 直近のメッセージ（話者名 + 本文） | 最大5件（設定可能）、マスク処理済み |
| `intent` | ユーザーが入力した返信意図 | テキストそのまま |
| `tone` | トーン指定 | 固定値のみ |
| `retryMode` | 再生成フラグ | boolean |
| `customPrompt` | カスタムシステムプロンプト（任意） | ユーザーが設定画面で入力した追加指示 |
| `templateName` | 使用テンプレート名（任意） | テンプレート名のみ（テンプレート本文は intent に反映）|

## どんな情報を送らない方針か

- Chatworkの過去全履歴
- ルーム一覧やメンバー一覧
- ファイル添付の内容
- Chatworkの認証トークン/Cookie
- ユーザーのChatworkアカウント情報
- ブラウザの他のタブや拡張の情報

## APIキーを拡張に置かない理由

Chrome拡張のソースコードはブラウザ上で誰でも閲覧可能です。
`chrome://extensions` からソースを確認できるため、拡張内にAPIキーを
埋め込むと以下のリスクがあります。

- APIキーが漏洩し、不正利用される
- 利用量の制御ができなくなる
- キーのローテーションが困難になる

**対策**: APIキーはn8nサーバー側（環境変数）でのみ管理する。
拡張機能は Webhook URL のみを保持し、APIキーには一切触れない。

## localStorage を避ける理由

`localStorage` は以下の理由で使用しません。

1. **永続保存**: ブラウザを閉じてもデータが残り続ける
2. **共有リスク**: 同じプロファイルを共有するユーザーがアクセスできる
3. **拡張間の分離**: 同じオリジンの他の拡張からアクセスされる可能性がある
4. **クリア忘れ**: ユーザーが明示的に消さない限り残り続ける
5. **容量制限なし**: 意図せず大量データが蓄積される

**対策**: 一時データは `chrome.storage.session`（ブラウザ終了で消える）
またはメモリ内変数（タブ遷移で消える）を使用する。
設定値（webhook URLなど）のみ `chrome.storage.local` を許容する。

## ログを最小化する理由

`console.log` に業務データを出力すると以下のリスクがあります。

1. DevTools を開いた状態でスクリーンショットを撮ると漏洩する
2. コンソールの履歴が残る
3. 他の拡張やスクリプトからコンソール出力を読み取られる可能性

**対策**:
- 会話本文や下書き本文は `console.log` に出力しない
- エラーログは要約メッセージのみ
- 開発用の詳細ログは `DEBUG` フラグで制御し、本番では OFF にする

## n8n の前段に社内保護レイヤーを置くべき理由

n8n の Webhook URL が外部に漏洩した場合、以下のリスクがあります。

1. 第三者が任意のデータを送りつけることができる
2. Gemini API の利用量が不正に消費される
3. 不適切なプロンプトを注入される可能性がある

**本番運用では以下を推奨**:

- 社内VPN内にn8nを配置する
- IP制限やBasic認証を設定する
- リバースプロキシ（nginx等）で認証レイヤーを追加する
- レートリミットを設定する
- WAF（Web Application Firewall）を導入する

## Gemini / Vertex AI 利用時の注意

- **利用規約**: 業務データをAIモデルに送信する場合、
  Google の利用規約（特にデータの取り扱いに関する条項）を確認すること
- **データの学習利用**: 無料版のGemini APIでは送信データが
  モデルの学習に使用される可能性がある。
  業務利用では Vertex AI（有料・データ学習なし）の使用を検討すること
- **リージョン**: データの送信先リージョンを確認し、
  社内のデータガバナンスポリシーに準拠すること

## 個人情報マスクの限界

`lib/mask-sensitive.js` による個人情報マスクは **簡易的なもの** です。

### マスクできるもの（ベストエフォート）

- メールアドレス（一般的な形式）
- 電話番号（日本の一般的な形式）
- 郵便番号
- クレジットカード番号らしき16桁数字列
- 8桁以上の連続数字（注文番号等）

### マスクできないもの

- 文脈から推測できる個人情報（「田中さん宛に送ってください」など）
- 漢字の住所
- カタカナの氏名
- 社内用語やコードネーム
- 画像内のテキスト
- 新しい形式の識別子

**この簡易マスクは「ないよりまし」程度のものであり、
完全な個人情報保護を保証するものではありません。**
本番運用ではサーバー側での追加のサニタイズを強く推奨します。

## 完全ゼロ保存は保証できないが、保存最小化設計であること

以下の理由により、データの「完全ゼロ保存」は技術的に保証できません。

1. ブラウザのメモリにはデータが一時的に存在する
2. OSのスワップ領域にデータが残る可能性がある
3. ネットワーク通信のキャッシュやログ
4. n8nサーバー側のログ

**しかし、この拡張機能は「保存最小化」を設計原則としています。**

- 意図的な永続保存は設定値のみ（webhook URL、メッセージ件数、
  カスタムプロンプト、テンプレート定義）
- 下書きの履歴は保存しない
- ページ遷移やブラウザ終了で一時データは消える
- chrome.storage.session はブラウザ終了で自動クリアされる

## 権限の最小化

manifest.json の権限は以下に限定しています。

| 権限 | 理由 |
|---|---|
| `storage` | 設定値（webhook URL等）の保存に必要 |
| `host_permissions: chatwork.com` | コンテンツスクリプトの実行に必要 |
| `host_permissions: kcw.kddi.ne.jp` | KDDI版Chatworkへの対応 |

以下の権限は**意図的に使用していません**。

- `<all_urls>` — 不要な全ドメインへのアクセス
- `tabs` — タブ情報へのアクセス
- `cookies` — Cookie読み取り
- `history` — 閲覧履歴
- `webRequest` — ネットワークリクエストの傍受

## カスタムプロンプト・テンプレートの安全性

### カスタムプロンプト

設定画面で入力されたカスタムプロンプトは `chrome.storage.local` に保存され、
リクエスト時に `customPrompt` フィールドとして n8n に送信されます。

**注意点**:
- カスタムプロンプトにはパスワードやAPIキーなどの機密情報を書かないこと
- n8n 側ではこの値をそのままシステムプロンプトに結合するため、
  プロンプトインジェクション対策を n8n 側で行うことを推奨
- カスタムプロンプトの内容自体は設定値であり、チャット内容ではないため
  永続保存を許容している

### テンプレート

テンプレートは以下の情報のみを保持します。

| フィールド | 内容 | 機密性 |
|---|---|---|
| `name` | テンプレート名 | 低（ユーザー定義のラベル） |
| `intent` | AIへの意図テキスト | 低（定型的な指示文） |
| `tone` | トーン | 低（固定値） |
| `icon` | 絵文字 | なし |
| `category` | カテゴリ名 | 低 |

- テンプレートにはチャットの実際の内容は含まれない
- テンプレートは設定値として `chrome.storage.local` に保存
- プリセットテンプレートはコード内の定数であり、保存対象外

## XSS / DOM安全性

- `innerHTML` の乱用を避ける
- ユーザー由来文字列は `textContent` ベースで表示する
- DOM要素の生成はヘルパー関数 `el()` で安全に行う
- 外部からの応答（下書きテキスト）も `textContent` で表示し、
  HTMLとして解釈させない
