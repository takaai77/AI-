✨ AI返信下書きサポート

設定画面

Webhook設定

n8n や中継サーバーの Webhook URL を設定してください。
AI生成リクエストはこのURLに送信されます。

https:// で始まるURLを入力してください。
APIキーはここには入力しないでください（サーバー側で管理します）。

n8n の Header Auth で設定したトークンを入力してください。
Authorization: Bearer ヘッダーとして送信されます。空欄の場合は認証なしで通信します。

コンテキスト設定

AIに送る直近メッセージの件数です。多いほど文脈は豊かになりますが、 送信データ量が増えます。推奨: 3〜5件

カスタムプロンプト

AIに追加の指示を与えたい場合に設定してください。
例: 「です・ます調で統一」「社名は株式会社○○」「敬語レベルを高めに」
空欄の場合はデフォルトの動作になります。

この内容は n8n 経由でAIに追加指示として送られます。
機密情報（パスワード、APIキー等）は絶対に書かないでください。

返信テンプレート管理

よく使う返信パターンをテンプレートとして保存できます。
カード上の「📋 テンプレートから選ぶ」から素早くアクセスできます。

新しいテンプレートを追加

セキュリティについて

  • APIキーはこの拡張機能内に保存しません（サーバー側で管理）
  • 送信データは直近の数件のメッセージのみです
  • 個人情報らしき文字列は送信前に自動マスクされます
  • 下書き履歴は永続的に保存しません
  • カスタムプロンプトとテンプレートは設定値として保存されます
  • この拡張機能は送信ボタンを自動で押しません
