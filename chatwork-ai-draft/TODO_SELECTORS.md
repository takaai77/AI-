# TODO: 実機で確認が必要なセレクタ一覧

このファイルは `lib/dom-selectors.js` で使用しているDOMセレクタのうち、
実際のChatwork Web版で動作確認が必要なものをまとめたものです。

ChatworkはSPA（シングルページアプリケーション）であり、
DOM構造やクラス名がビルドごとに変わる可能性があります。
セレクタが動作しない場合は、DevToolsで実際の要素を確認して更新してください。

## 確認方法

1. Chatwork Web版（`https://www.chatwork.com/`）にログインする
2. Chrome DevTools を開く（F12 または Cmd+Option+I）
3. Elements パネルで対象要素を右クリック → 「Copy selector」
4. Console パネルで `document.querySelector('セレクタ')` を実行して確認
