ステージ1：たおしたモンスター（かいけつずみ！）

10体のモンスターをやっつけたよ 🎉
▶
👾 ボス：リモートのっとりモンスター（RCE） ✅ クリア

🧒 かんたん説明：カギをかけわすれたドアから、わるい人がかってに入ってこれたよ。いまはちゃんとカギがかかった！

  • ブラウザ操作のドアに「カギなし」で入れた → 1クリックでのっとり＆パスワードぬすみが可能だった
  • 🔧 修正（v2.12）：カギ（認証）を必ずつけるようにした。カギがなければ自動で作る
🕵️ スパイモンスター（SSRF） ✅ クリア

🧒 かんたん説明：AIをだまして「ないしょの場所」をのぞかせるワザ。いまはAIが「のぞいちゃダメ」リストを持ってる！

  • AIをだまして、ないしょのネットワークを調べさせられた
  • 🔧 修正（v2.12）：のぞいちゃダメリスト＋しらべる回数制限＋記録（ログ）を追加
🔓 カギなし設定へんこうモンスター ✅ クリア

🧒 かんたん説明：だれでもAIの設定をかえられた。いまはパスワードが必要！

  • プロフィール設定がカギなしで変更できた
  • 🔧 修正（v2.12）：パッチで修正ずみ
🎭 なりすましモンスター（セッションハイジャック） ✅ クリア

🧒 かんたん説明：ほかの人の「おへや」にこっそり入れた。いまは「おへやのカギ」の上書きはきんし！

  • セッションキーを上書きして、ほかの人のセッションに入れた
  • 🔧 修正（v2.12）：カギの上書きをデフォルトで「きんし」にした
📂 ファイル脱出モンスター（ディレクトリトラバーサル） ✅ クリア

🧒 かんたん説明：「スキル」のなまえをズルして、さわっちゃいけないファイルに書きこめた。いまはスキル専用のお部屋しかつかえない！

  • スキルの名前をパスとして悪用し、サンドボックスの外に書きこみ可能だった
  • 🔧 修正（v2.12＋v2.15）：スキル専用フォルダに制限
🌐 Webわなモンスター（プロンプトインジェクション再送） ✅ クリア

🧒 かんたん説明：わるいWebページに「こっそりめいれい」がかくれていて、AIがだまされた。いまはWebのことばを「しんようしない」ようになった！

  • Webコンテンツ内の隠し命令がそのままAIに実行された
  • 🔧 修正（v2.12）：Webコンテンツを「デフォルト信用しない」に変更
📦 コンテナ脱走モンスター ✅ クリア

🧒 かんたん説明：「安全なはこ（コンテナ）」からぬけだす方法があった。いまは、はこのカベがもっとがんじょうになった！

  • サンドボックスの設定であぶない機能を有効にできた
  • 🔧 修正（v2.15）：危険な設定をブロック＋暗号化を強化（SHA-256へ）
🔑 パスワードもれモンスター（情報漏洩） ✅ クリア

🧒 かんたん説明：ひみつのパスワードが日記（ログ）に書いてあって、みんなに見えてた。いまはかくしてある！

  • Telegramトークンがログに丸見え、セッション詳細が非管理者にも見えた
  • 🔧 修正（v2.15）：トークンを隠し、セッション情報を制限
💉 注入モンスター（XSS・インジェクション） ✅ クリア

🧒 かんたん説明：チャット画面にワルいスクリプト（おまじない）をしこめた。いまは「おまじないきんし」フィルターがついた！

  • コントロールUIでXSS、チャットで制御文字の注入が可能だった
  • 🔧 修正（v2.15）：スクリプト制限＋制御文字の除去＋Unicode正規化
🗂️ かくし文字モンスター（パス経由インジェクション） ✅ クリア

🧒 かんたん説明：フォルダの名前に「目に見えないめいれい」をかくせた。いまは見えない文字をぜんぶ消してから使う！

  • ディレクトリ名にUnicode制御文字を仕込み、AIへの命令を注入できた
  • 🔧 修正（v2.15）：パスに入れる前にUnicode制御文字を除去
🛡️

ステージ2：よわくなったけど、まだいるモンスター

だいぶよわくしたけど、まだ気をつけてね 🟡
▶
🧪 にせスキルモンスター（ClawHub悪意スキル） 🟡 よわくなった

🧒 かんたん説明：スキルの「おみせ（ClawHub）」にニセモノが20%もあった！いまはウイルスチェックで大そうじしたけど、コピーがネットに残ってることがある

  • 約900個のワルいスキルが存在（Bitdefender調査）
  • ✅ 2026年2月にVirusTotal提携で3,016スキルを自動分析し削除
  • ⚠️ GitHubにコピーが残っている可能性あり
🏠 「じもと」なりすましモンスター（localhost信頼バイパス） 🟡 設定しだい

🧒 かんたん説明：とおくからのアクセスを「すぐそば」と思いこませられた。いまは「ほんとうの友だちリスト」を作れるけど、ちゃんと設定しないとダメ

  • リバースプロキシ経由の接続がすべてローカルに見えた
  • ✅ trustedProxies設定を導入
  • ⚠️ ユーザーが正しく設定しないとバイパス可能
🔌 つなぎっぱなしモンスター（WebSocket保護） 🟡 よくなった

🧒 かんたん説明：だれでも「直通の電話線」をつなげた。いまは電話するのにパスワードが必要。ただしパスワードのつよさは自分しだい

  • どこからでもWebSocket接続できた
  • ✅ Gateway認証がデフォルト必須に（カギなし＝つながらない）
  • ⚠️ トークンの強さ・管理はユーザー次第
🔍 日本語けんさくモンスター（CJK検索） 🟡 よくなった

🧒 かんたん説明：日本語でさがしものすると、ちゃんと見つからなかった。いまはだいぶよくなったけど、AIのかしこさに影響するよ

  • 日本語の検索がベクトル検索のみにフォールバックしていた
  • ✅ v2.15でUnicode対応に改善
  • ⚠️ セキュリティ直結ではないが、AIの判断品質に影響
🐉

ステージ3：たおせないラスボスたち（こうぞう的リスク）

アプデだけではたおせない。ずっと気をつけるしかない 🔴
▶
🐉 3つのチカラが合体！「さんじゅうく」のドラゴン 🔴 たおせない

🧒 かんたん説明：「ひみつのデータを見れる」＋「しらないWebを見る」＋「外にメッセージを送れる」の3つが合わさると、どうしてもキケンが残る。これはOpenClawのできることそのものだから、なくすことはできない。ばくはつ（ひがい）を小さくするしかない！

  • プライベートデータアクセス＋非信頼コンテンツ＋外部通信＝設計上の特性
  • パッチでは直せない → ひがいを最小限にするアプローチが必要
🧙 ことばのまほうモンスター（プロンプトインジェクション） 🔴 業界全体のもんだい

🧒 かんたん説明：AIは「データ」と「めいれい」のくべつがにがて。ワルい「ことばのまほう」でAIをだませる問題は、世界中のAI全部がかかえている。OpenClawだけのもんだいじゃないよ。いまは「サンドボックス」と「つかえるツールを制限」してひがいを減らしてる

  • v2.12でWebコンテンツの非信頼化、v2.15でパス経由の防止は実装ずみ
  • 「AIがデータと命令を区別できない」という根本問題は未解決
  • Opus 4.6推奨＋サンドボックス＋ツール制限で被害を限定する方針
😴 アプデしないモンスター（運用/設定ミス） 🔴 人間のもんだい

🧒 かんたん説明：せっかくバグをなおしても、アプデしなかったら意味がない！じつは13万5千台以上のOpenClawがインターネットにむき出しになっている（SecurityScorecard調査）。ゲームでいうと「つよい防具があるのに装備してない」状態！

  • パッチが出てもアップデートしないユーザーが多数
  • OpenClaw側の問題ではなく運用側の問題
🏗️ チームたいせいモンスター（組織の課題） 🔴 これから

🧒 かんたん説明：バグを見つけてくれた人にごほうびをあげるしくみ（バグバウンティ）がまだない。セキュリティ専門のチームもいない。みんなでつくるソフト（OSS）のいいところはあるけど、会社で使うにはまだ心配なところもある

  • バグバウンティプログラムなし、専任セキュリティチームなし
  • コミュニティ貢献者40名超で活発だが、体系的レビュー体制は未整備

🏆 ぼうけんのまとめ

v2026.2.12〜2.15のアップデートで、「みつかった具体的な攻撃ルート」はかなりふさがれたよ！ とくにRCE・SSRF・セッションハイジャック・XSSといった大きなモンスターはたおされた。

でも、「AIが強い力をもつ」という構造的なリスクとプロンプトインジェクションは、 OpenClawだけじゃなく世界中のAI全部の課題。

だから大事なのは：
🔄 アプデする ＋ ⚙️ 正しく設定する ＋ 🔒 さいしょう権限にする ＋ 📋 ときどきチェックする
この4つをセットでやること！

ぎゃくに言えば、ここまでセキュリティ修正に本気でとりくんでいるOSSのAIフレームワークはめずらしいよ 🦞🔐
