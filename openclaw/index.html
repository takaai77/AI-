OpenClaw セットアップガイド

OpenClaw はオープンソースのパーソナルAIアシスタントです。 PCで Gateway を起動し、iPhone からも接続できます。

1 前提条件の確認

以下が必要です:

  • Node.js v22 以上 — nodejs.org
  • Anthropic API キー (Claude) または OpenAI API キー
  • PC (macOS / Linux / Windows WSL2)

2 OpenClaw のインストール

PC で実行

ターミナルで以下を実行:

npm install -g openclaw@latest
openclaw onboard --install-daemon

または、このリポジトリのセットアップスクリプトを使用:

bash openclaw/setup.sh

オンボーディングウィザードが順番にガイドします。

3 Gateway を起動

PC で実行 
openclaw gateway --port 18789 --verbose

起動後、WebChat が以下で利用可能になります:

http://127.0.0.1:18789/chat

4 iPhone から接続

iPhone

App Store から OpenClaw をインストール:

App Store で開く

接続方法 A: 自動検出 (同じ Wi-Fi)

  • iPhone と PC を同じ Wi-Fi ネットワークに接続
  • OpenClaw アプリを開くと Gateway が自動検出されます
  • タップして接続

接続方法 B: 手動接続

  • OpenClaw アプリ > Settings を開く
  • Manual Host を有効にする
  • Gateway の IPアドレス:18789 を入力

PC の IP アドレスの確認方法:

# macOS
ipconfig getifaddr en0

# Linux
hostname -I | awk '{print $1}'

接続方法 C: リモートアクセス (外出先)

  • Tailscale を使用してどこからでも接続可能
openclaw tailscale serve

5 iPhone でできること

Canvas

AIが生成するビジュアルをリアルタイム表示

Voice Mode

音声で会話。ハンズフリー操作

Camera

カメラ画像をAIに送信して分析

WebChat

Safari からもアクセス可能

設定ファイル

このプロジェクト用の設定は openclaw/openclaw.json にあります。 セットアップスクリプトが ~/.openclaw/openclaw.json にコピーします。

{
  "agent": {
    "model": "anthropic/claude-opus-4-6",
    "thinking": "medium",
    "systemPrompt": "AI-学習サイトのアシスタント..."
  },
  "channels": {
    "webchat": { "enabled": true }
  },
  "nodes": {
    "ios": { "enabled": true }
  }
}
