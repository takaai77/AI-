# カスタマサポートアプリ 要件定義（OP向け）

更新日: 2026-02-23  
対象実装: `Development/zendesk-op-ui/zendesk-preview/src/App.jsx`（`data-build="20260223-2015"`）

## 1. 背景と目的
- 電話対応中のOPが、迷わず最短操作で「注文確認・変更」を実行できるUIを提供する。
- OPは「定期マスタ/子注文」の概念を意識しない運用を前提とし、基本は子注文ベースで変更する。
- 最重要確認情報は「次回注文の子注文内容」と「実際の請求金額」。

## 2. 利用者
- 主利用者: コールセンターOP（非エンジニア）
- 想定端末: PCブラウザ（スマホ幅UIをPC内で表示）

## 3. 画面全体構成
- ヘッダー: `カスタマサポートアプリ`
- STEP 1: `検索`
  - 電話/メール/顧客ID/氏名検索
  - `新規登録` 導線（低頻度）
- STEP 2: `登録情報`
  - 顧客基本情報の要約表示
  - 鉛筆アイコンで編集シートを開く
- STEP 3: `操作対象`
  - 操作する定期（対象）を選択
  - このエリアでは注文ステータスタグ（発送待ち等）を表示しない
- タブ:
  - `注文詳細/変更`
  - `注文履歴`

## 4. 主要業務要件

### 4-1. 注文詳細/変更タブ
- 定期ステータスを明示:
  - `継続中` または `停止中`
- ステータス近傍に主要操作を常設:
  - `定期停止`（停止中の場合は `定期再開`）
  - `キャンセル処理`
- 次回注文カードに表示:
  - 注文番号（例: `EP2404`）と注文ID
  - 子注文明細（商品行）
  - `ポイント利用`
  - 必要時のみ `クーポン`、`送料`
  - `今回の請求合計` は明細の最下部（ポイント利用より下）

### 4-2. 子注文明細の個別編集
- 商品行ごとに編集可能（鉛筆）。
- 編集内容:
  - 数量
  - 単価
  - 単品追加行は削除可
- ポイント利用も個別編集可能（鉛筆）。

### 4-3. 単品注文運用
- 定期なし顧客でも対応できること。
- 単品テンプレ作成:
  - `単品別送`
  - `お詫び別送`
  - `差し替え発送`
- 注文履歴の `単品注文` セクションから:
  - `編集` で単品注文編集シートを開く
  - 保存で更新
  - キャンセル処理可能

### 4-4. 低頻度業務
- 未注文顧客の `新規登録`（顧客情報+初回注文）を2ステップで実行可能。

## 5. 業務ルール（重要）
- 変更の基本対象は子注文。
- 子注文が編集不可（確定済み等）の場合は、次回注文反映メッセージで明示する。
- 合計金額計算:
  - `totalAmount = lineItems合計 - pointsUsed - couponDiscount + shippingFee`
  - 下限は0円
- お届け日変更では、発送日の自動算出・手動変更・例外運用（13時以降）を扱える。

## 6. データ要件（最小）

### 6-1. 顧客
- `name`, `kana`, `id`, `phone`, `email`, `address`
- `memberType`, `dmOptIn`, `newsletterOptIn`, `outboundBlocked`, `customerMemo`

### 6-2. 定期（subscription）
- `id`, `label`, `freqKey`, `freqLabel`, `months`, `nextDate`
- `course`, `status(active|paused)`, `pauseReason`, `pausedAt`
- `items[]`, `price`, `timeSlot`, `payment`, `count`
- `latestOrder`
- `child`（次回注文に紐づく子注文）

### 6-3. 子注文（child）
- `id`, `editable`, `lockReason`
- `shipDate`, `deliveryDate`, `status`, `deadline`
- `lineItems[]`:
  - `type` (`subscription` / `single_add`)
  - `name`, `size`, `qty`, `price`
- `pointsUsed`, `couponDiscount`, `shippingFee`, `totalAmount`

### 6-4. 注文履歴（orders）
- 単品/定期混在
- `isSingle` で単品判定

## 7. 非機能要件
- OPが迷わない文言優先（重複説明は削減）。
- 1画面で主要判断が完了する情報配置。
- 見た目は柔らかい配色、可読性重視、モバイル幅レイアウトをPCで再現。

## 8. ファイル構成（現行）

- `zendesk-v12.jsx`（単体スナップショット）

## 9. 受け入れ基準（UAT）
- STEP 3見出しが `操作対象` である。
- STEP 3の定期一覧に「発送待ち等」の注文ステータスタグが出ない。
- タブ名が `注文詳細/変更` である。
- 注文詳細で `今回の請求合計` が明細の最下部にある。
- 商品明細とポイント利用を個別編集できる。
- 単品注文を履歴から編集・キャンセルできる。
- 定期停止/再開とキャンセル処理が定期ステータス近傍にある。

## 10. 起動・確認手順
- 開発:
  - `cd Development/zendesk-op-ui/zendesk-preview`
  - `npm install`
  - `npm run dev -- --host 127.0.0.1 --port 4180`
- 本番相当表示:
  - `npm run build`
  - `npm run preview -- --host 127.0.0.1 --port 4180`
