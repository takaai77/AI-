# AI Repository

このリポジトリは、AI を使った試作・業務ツール・UI 実験をまとめる作業場です。

## Apps

- `apps/phone-ai-agent`
  - 定期便の停止・変更を受け付ける電話 AI
  - ブラウザから OpenAI / Gemini を切り替えて確認可能
  - プロンプト入力欄とノード型シナリオ編集あり
- `apps/sheets-worker-poc`
  - Google Sheets をジョブ台帳に使う PoC
- `apps/zendesk-op-ui`
  - Zendesk オペレーション UI の試作

## これから読み始めるなら

まずは `apps/phone-ai-agent/README.md` を見てください。  
設計の学習用ドキュメントは `apps/phone-ai-agent/docs/` にまとめています。
