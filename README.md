# 🎬 動画分析 Pro Max

**業界標準を超える包括的動画分析プラットフォーム**

動画広告分析proを徹底リサーチし、それを超える実務レベルのシステムを実現しました。

## ✨ 主な機能

### 🎯 4つの分析モード

- **📺 広告分析**: CTR予測、ターゲット層分析、競合比較、改善提案
- **🎬 映画分析**: 物語構造、演出技法、映画文法、芸術性評価
- **📺 ドラマ分析**: エピソード構造、視聴維持率、シリーズ展開可能性
- **🌟 総合分析**: 全ての観点から徹底的に分析

### 🤖 AI統合

- **Claude 3.5 Sonnet**: 最高精度の詳細分析
- **Google Gemini 1.5 Pro**: 高速処理
- ワンクリックで切り替え可能

### 🚀 自動化機能（実務レベル）

- **⏰ 自動スケジューリング**: 指定時刻に自動実行
- **🔄 バッチ処理**: 複数動画の一括分析
- **24/7 稼働**: サーバー稼働中は自動で処理継続
- **📊 自動レポート生成**: HTML/テキスト形式

### 💾 データ管理

- **SQLite データベース**: 全分析結果を永続保存
- **検索・フィルタリング**: 高速検索機能
- **統計ダッシュボード**: リアルタイム統計
- **エクスポート機能**: レポートダウンロード

## 📦 セットアップ

### 必要環境

- Python 3.8以上
- pip（パッケージマネージャー）
- インターネット接続

### インストール手順

1. **リポジトリをクローン**

```bash
cd AI-
```

2. **仮想環境を作成（推奨）**

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

3. **依存パッケージをインストール**

```bash
pip install -r requirements.txt
```

### APIキーの取得

#### Claude API

1. [Anthropic Console](https://console.anthropic.com/)にアクセス
2. アカウント作成
3. API Keysセクションで新しいキーを生成
4. キーをコピー（`sk-ant-api03-...`で始まる）

#### Google Gemini API

1. [Google AI Studio](https://aistudio.google.com/app/apikey)にアクセス
2. 「Get API Key」をクリック
3. キーをコピー（`AIza...`で始まる）

## 🚀 起動方法

### 基本起動

```bash
streamlit run app.py
```

ブラウザが自動で開き、`http://localhost:8501`でアプリケーションが起動します。

### バックグラウンド起動（24/7稼働）

```bash
# nohupで起動（Linux/Mac）
nohup streamlit run app.py --server.port 8501 &

# または、screenを使用
screen -S video-analysis
streamlit run app.py
# Ctrl+A, Dでデタッチ
```

## 📖 使い方

### 1. 基本的な動画分析

1. サイドバーでAIプロバイダーを選択
2. APIキーを入力
3. 「📹 動画分析」タブで分析タイプを選択
4. 動画URLを入力
5. 「🎬 分析開始」をクリック

**処理時間**: 約2-5分（動画の長さにより変動）

### 2. 自動スケジューリング

1. サイドバーで「▶️ 開始」をクリックしてスケジューラーを起動
2. 「⏰ スケジュール」タブを開く
3. 動画URL、分析タイプ、実行日時を入力
4. 「➕ スケジュール追加」をクリック
5. **指定時刻に自動で分析が実行されます**

**重要**: サーバー（Streamlitアプリ）が稼働している必要があります。

### 3. バッチ処理

1. 「🔄 バッチ処理」タブを開く
2. 複数の動画URLを入力（1行に1つ）
3. 「➕ バッチキューに追加」をクリック
4. 「🚀 バッチ処理開始」をクリック
5. **放置するだけで全て自動処理**

**使用例**: 夜寝る前に10本の動画をセットして、朝起きたら全て完了！

### 4. 履歴管理

- 「📚 履歴」タブで過去の分析結果を閲覧
- 検索・フィルタリング機能で素早く見つける
- HTML/テキスト形式でダウンロード可能

## 🔧 技術スタック

- **フロントエンド**: Streamlit
- **動画処理**: yt-dlp, OpenCV

- **データベース**: SQLite + SQLAlchemy
- **スケジューリング**: APScheduler
- **画像処理**: Pillow

```
AI-/
├── app.py                 # メインアプリケーション

├── database.py            # データベース管理
├── video_processor.py     # 動画処理モジュール
├── ai_analyzer.py         # AI分析モジュール
```

## ⚡ パフォーマンス

- **フレーム抽出**: 約30-60秒（動画の長さによる）
- **AI分析**: 約1-3分（フレーム数とAIプロバイダーによる）
- **バッチ処理**: 1動画あたり約2-5分
- **データベース**: 1万件以上の分析結果を高速管理

## 🛡️ セキュリティ

- APIキーはセッション内のみで保持
- データはローカルに保存（外部送信なし）
- ダウンロード動画は自動削除オプション付き
