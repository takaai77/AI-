💡 まずはここから！

Playwrightを使うには、まずNode.jsをインストールする必要があります。下のコマンドを順番に実行してね！

ステップ1: Node.jsをインストール

Node.jsの公式サイト（https://nodejs.org）からLTS版をダウンロードしてインストールしてね。

ステップ2: プロジェクトを作成

# フォルダを作成して移動 mkdir my-first-automation cd my-first-automation # プロジェクトを初期化 npm init -y # Playwrightをインストール npm install playwright

ステップ3: はじめてのスクリプトを作成

// hello-playwright.js const { chromium } = require('playwright'); (async () => { // ブラウザを起動（headless: false で画面表示） const browser = await chromium.launch({ headless: false }); // 新しいページを開く const page = await browser.newPage(); // Googleにアクセス await page.goto('https://www.google.com'); // 3秒待つ（結果を見るため） await page.waitForTimeout(3000); // ブラウザを閉じる await browser.close(); console.log('🎉 おめでとう！はじめてのPlaywrightが動いたよ！'); })();

ステップ4: 実行してみよう！

node hello-playwright.js

✨ 成功！

ブラウザが自動で開いてGoogleにアクセスしたら成功だよ！これであなたもPlaywright使いの仲間入り！
