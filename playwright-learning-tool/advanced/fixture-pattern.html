❓ Fixtureとは？

Fixtureは「テストの前準備」を再利用可能な形でまとめたものです。

❌ Fixtureなし（毎回同じ処理）

test('テスト1', async ({ page }) => { // 毎回ログイン処理を書く... await page.goto('/login'); await page.fill('#email', 'test@example.com'); await page.fill('#password', 'password'); await page.click('button[type="submit"]'); // 本来のテスト... }); test('テスト2', async ({ page }) => { // また同じログイン処理... await page.goto('/login'); await page.fill('#email', 'test@example.com'); // ... });

✅ Fixtureあり（再利用）

// Fixtureで認証済みページを提供 test('テスト1', async ({ authenticatedPage }) => { // 即座にテスト開始！ await authenticatedPage.goto('/mypage'); }); test('テスト2', async ({ authenticatedPage }) => { // 同じFixtureを使用 await authenticatedPage.goto('/orders'); });

📦 Playwrightの組み込みFixture

Playwrightには便利なFixtureが最初から用意されています。

import { test, expect } from '@playwright/test'; // 組み込みFixtureの例 test('組み込みFixtureを使う', async ({ page, // ブラウザのページ context, // ブラウザコンテキスト browser, // ブラウザインスタンス request, // APIリクエスト用 browserName // "chromium" | "firefox" | "webkit" }) => { // pageは最もよく使うFixture await page.goto('https://example.com'); // requestでAPIテスト const response = await request.get('/api/users'); expect(response.ok()).toBeTruthy(); // browserNameで条件分岐 if (browserName === 'webkit') { // Safari固有の処理 } });

🛠️ カスタムFixtureの作成

基本的なカスタムFixture

// fixtures.ts import { test as base } from '@playwright/test'; // カスタムFixtureの型定義 type MyFixtures = { authenticatedPage: Page; testUser: { email: string; password: string }; }; // Fixtureを拡張 export const test = base.extend<MyFixtures>({ // テストユーザーFixture testUser: async ({}, use) => { const user = { email: 'test@example.com', password: 'securePassword123' }; await use(user); }, // 認証済みページFixture authenticatedPage: async ({ page, testUser }, use) => { // セットアップ: ログイン処理 await page.goto('/login'); await page.fill('[data-testid="email"]', testUser.email); await page.fill('[data-testid="password"]', testUser.password); await page.click('[data-testid="login-button"]'); await page.waitForURL('/dashboard'); // Fixtureを提供 await use(page); // クリーンアップ: ログアウト await page.goto('/logout'); } }); export { expect } from '@playwright/test';

使用例

// tests/mypage.spec.ts import { test, expect } from './fixtures'; test('マイページにアクセスできる', async ({ authenticatedPage }) => { // すでにログイン済み！ await authenticatedPage.goto('/mypage'); await expect(authenticatedPage.getByText('ようこそ')).toBeVisible(); }); test('注文履歴を確認できる', async ({ authenticatedPage }) => { await authenticatedPage.goto('/mypage/orders'); await expect(authenticatedPage.getByText('注文履歴')).toBeVisible(); });

🛒 EC特化のFixture例

// fixtures/ec-fixtures.ts import { test as base, Page } from '@playwright/test'; import { CartPage } from '../pages/CartPage'; import { CheckoutPage } from '../pages/CheckoutPage'; type ECFixtures = { cartPage: CartPage; checkoutPage: CheckoutPage; cartWithItems: CartPage; testProducts: Array<{ id: string; name: string; price: number }>; }; export const test = base.extend<ECFixtures>({ // テスト用商品データ testProducts: async ({}, use) => { const products = [ { id: 'PROD001', name: 'テスト商品A', price: 1000 }, { id: 'PROD002', name: 'テスト商品B', price: 2500 }, { id: 'PROD003', name: 'テスト商品C', price: 500 } ]; await use(products); }, // CartPage インスタンス cartPage: async ({ page }, use) => { const cartPage = new CartPage(page); await use(cartPage); }, // CheckoutPage インスタンス checkoutPage: async ({ page }, use) => { const checkoutPage = new CheckoutPage(page); await use(checkoutPage); }, // 商品入りカート（セットアップ済み） cartWithItems: async ({ page, testProducts }, use) => { const cartPage = new CartPage(page); // セットアップ: 商品をカートに追加 for (const product of testProducts) { await page.goto(`/products/${product.id}`); await page.click('[data-testid="add-to-cart"]'); } await page.goto('/cart'); await use(cartPage); // クリーンアップ: カートを空にする await cartPage.clearCart(); } });

EC Fixtureの使用例

// tests/ec-checkout.spec.ts import { test, expect } from './fixtures/ec-fixtures'; test.describe('ECチェックアウト', () => { test('カート内商品で購入手続きできる', async ({ cartWithItems, checkoutPage, testProducts }) => { // cartWithItemsは既に3商品入り！ const itemCount = await cartWithItems.getItemCount(); expect(itemCount).toBe(testProducts.length); // 合計金額を確認 const expectedTotal = testProducts.reduce((sum, p) => sum + p.price, 0); const actualTotal = await cartWithItems.getSubtotal(); expect(actualTotal).toBe(expectedTotal); // 購入手続きへ await cartWithItems.proceedToCheckout(); // checkoutPageで続きのテスト... }); test('空のカートでは購入できない', async ({ cartPage, page }) => { // cartPageは空の状態 await page.goto('/cart'); await expect(page.getByText('カートは空です')).toBeVisible(); }); });

⚡ 高度なFixtureテクニック

Worker-scoped Fixture（並列実行での共有）

// 全テストで共有するFixture（Worker単位） export const test = base.extend<{}, { sharedApiClient: APIClient }>({ sharedApiClient: [async ({}, use) => { // 重い初期化処理（1回だけ実行） const client = new APIClient(); await client.initialize(); await use(client); // Worker終了時にクリーンアップ await client.close(); }, { scope: 'worker' }] });

オプショナルFixture

// テストごとにカスタマイズ可能なFixture type TestOptions = { userRole: 'admin' | 'member' | 'guest'; }; export const test = base.extend<TestOptions>({ userRole: ['member', { option: true }] }); // 使用時にオーバーライド test.use({ userRole: 'admin' }); test('管理者機能をテスト', async ({ page, userRole }) => { console.log(userRole); // 'admin' });
