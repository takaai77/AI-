Week 2 - レッスン 4/5

📊 ページ情報を取得

テキストや属性値を読み取ろう！

📖 情報取得の基本

Webページからテキストや値を読み取る方法を学びます。スクレイピング（データ収集）に必須のスキル！

メソッド取得できるもの
textContent()要素内のテキスト
innerText()見えているテキスト
inputValue()入力欄の値
getAttribute()属性の値
count()要素の数
isVisible()表示されているか
isEnabled()有効かどうか

📝 テキストを取得

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); await page.goto('https://example.com'); // 要素のテキストを取得 const title = await page.locator('h1').textContent(); console.log('タイトル:', title); // 複数の要素のテキストを配列で取得 const items = await page.locator('p').allTextContents(); console.log('段落一覧:', items); await browser.close(); })();

💡 textContent と innerText の違い

textContent は非表示要素も含む全テキスト、innerText は画面に見えているテキストだけ取得します。

🏷️ 属性値を取得

// リンクのURL（href属性）を取得 const href = await page.locator('a').getAttribute('href'); console.log('リンク先:', href); // 画像のURL（src属性）を取得 const src = await page.locator('img').getAttribute('src'); console.log('画像URL:', src); // 入力欄のプレースホルダーを取得 const placeholder = await page.locator('input').getAttribute('placeholder'); console.log('プレースホルダー:', placeholder);

📋 実践例: ニュースタイトル収集

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); await page.goto('https://news.yahoo.co.jp'); // ニュースの見出しを取得 const headlines = page.locator('article h2'); const count = await headlines.count(); console.log(`📰 ${count}件のニュースを発見！`); // 各見出しを表示 for (let i = 0; i < count && i < 5; i++) { const text = await headlines.nth(i).textContent(); console.log(`${i + 1}. ${text}`); } await browser.close(); })();

✅ 状態を確認

// 要素が表示されているか const isVisible = await page.locator('#modal').isVisible(); console.log('モーダル表示中:', isVisible); // ボタンが有効か（クリックできるか） const isEnabled = await page.locator('button').isEnabled(); console.log('ボタン有効:', isEnabled); // チェックボックスがチェックされているか const isChecked = await page.locator('input[type="checkbox"]').isChecked(); console.log('チェック済み:', isChecked); // 要素の数 const count = await page.locator('.item').count(); console.log('アイテム数:', count);

🎯 このレッスンのまとめ

  • textContent() - テキストを取得
  • allTextContents() - 全要素のテキストを配列で
  • getAttribute() - 属性値を取得
  • inputValue() - 入力値を取得
  • count() - 要素数を取得
  • isVisible() / isEnabled() - 状態確認
