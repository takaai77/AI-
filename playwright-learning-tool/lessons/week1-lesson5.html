Week 1 - レッスン 5/5

📸 スクリーンショットを撮ろう

ページを画像として保存しよう！

📷 スクリーンショットの基本

Playwrightでは、ブラウザの画面を画像として保存できます。これをスクリーンショットと言います。

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); // Googleにアクセス await page.goto('https://www.google.com'); // スクリーンショットを撮影 await page.screenshot({ path: 'google.png' }); console.log('📸 スクリーンショットを保存しました！'); await browser.close(); })();

💡 ファイルはどこに？

スクリーンショットは、スクリプトと同じフォルダに保存されます。google.png というファイルを探してみよう！

⚙️ スクリーンショットのオプション

いろんなオプションで、撮影方法を変えられます。

1. フルページを撮影

// ページ全体（スクロールが必要な部分も含めて）を撮影 await page.screenshot({ path: 'fullpage.png', fullPage: true });

2. 特定のエリアだけ撮影

// 座標を指定して一部分だけ撮影 await page.screenshot({ path: 'partial.png', clip: { x: 0, // 左端からの位置 y: 0, // 上端からの位置 width: 500, // 幅 height: 300 // 高さ } });

3. JPEG形式で保存

// JPEG形式（ファイルサイズが小さい） await page.screenshot({ path: 'screenshot.jpg', type: 'jpeg', quality: 80 // 品質（0-100） });
オプション 説明
path 保存するファイル名
fullPage true にするとページ全体を撮影
clip 撮影範囲を指定（x, y, width, height）
type 'png' または 'jpeg'
quality JPEG品質（0-100）

🎯 特定の要素だけ撮影

ページ全体ではなく、特定のボタンや画像だけを撮影することもできます。

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); await page.goto('https://www.google.com'); // 検索ボックスを見つける const searchBox = page.locator('input[name="q"]'); // その要素だけスクリーンショット await searchBox.screenshot({ path: 'search-box.png' }); console.log('📸 検索ボックスだけ撮影しました！'); await browser.close(); })();

📝 locator って？

locator() は「要素を見つける」ためのコマンドです。Week 2で詳しく学びます！

📁 実践: 複数サイトのスクリーンショット

複数のサイトを巡回して、それぞれのスクリーンショットを撮ってみよう！

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); // 撮影するサイトのリスト const sites = [ { url: 'https://www.google.com', name: 'google' }, { url: 'https://www.yahoo.co.jp', name: 'yahoo' }, { url: 'https://www.youtube.com', name: 'youtube' } ]; for (const site of sites) { console.log(`📸 ${site.name} を撮影中...`); await page.goto(site.url); await page.screenshot({ path: `${site.name}.png`, fullPage: true }); console.log(`✅ ${site.name}.png を保存しました！`); } console.log('🎉 全サイトの撮影完了！'); await browser.close(); })();

🏋️ 練習問題

チャレンジ1: タイムスタンプ付きスクリーンショット

ファイル名に日時を入れて、いつ撮影したかわかるようにしよう！

// 現在の日時をファイル名に使う const now = new Date(); const timestamp = now.toISOString().replace(/[:.]/g, '-'); const filename = `screenshot-${timestamp}.png`; await page.screenshot({ path: filename }); console.log(`保存: ${filename}`);

チャレンジ2: screenshotsフォルダに保存

専用フォルダを作って、そこにスクリーンショットを整理しよう！

const fs = require('fs'); // フォルダがなければ作成 if (!fs.existsSync('screenshots')) { fs.mkdirSync('screenshots'); } // フォルダ内に保存 await page.screenshot({ path: 'screenshots/google.png' });
