Week 2 - レッスン 1/5

🖱️ ボタンをクリックしよう

Webページの要素をクリックする方法を学ぼう！

🎯 クリックの基本

Webページにはたくさんのクリックできる要素があります：

  • ボタン
  • リンク
  • メニュー
  • チェックボックス
  • 画像

Playwrightでは、click() を使ってこれらをクリックできます。

↓ 実際にクリックしてみよう！

📝 クリックのコード

方法1: テキストでクリック（おすすめ！）

// 「ログイン」というテキストのボタンをクリック await page.getByText('ログイン').click(); // 「送信」ボタンをクリック await page.getByText('送信').click(); // リンクをクリック await page.getByText('詳細はこちら').click();

💡 getByText() のメリット

画面に見えているテキストで指定するので、直感的でわかりやすい！初心者には一番おすすめの方法です。

方法2: ロール（役割）でクリック

// 「検索」という名前のボタンをクリック await page.getByRole('button', { name: '検索' }).click(); // 「ホーム」というリンクをクリック await page.getByRole('link', { name: 'ホーム' }).click();

方法3: CSSセレクタでクリック

// IDで指定 await page.locator('#submit-button').click(); // クラスで指定 await page.locator('.login-btn').click(); // タグで指定 await page.locator('button').click();

🔧 クリックのオプション

コード 説明
.click() 通常のクリック
.dblclick() ダブルクリック
.click({ button: 'right' }) 右クリック
.click({ clickCount: 3 }) トリプルクリック
.hover() マウスを乗せる（クリックなし）
// ダブルクリック await page.getByText('編集').dblclick(); // 右クリック（コンテキストメニューを開く） await page.locator('#target').click({ button: 'right' }); // マウスを乗せる（ホバー） await page.getByText('メニュー').hover();

📖 実践例: Google検索

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); // Googleにアクセス await page.goto('https://www.google.com'); // 検索ボックスをクリック await page.locator('input[name="q"]').click(); console.log('✅ 検索ボックスをクリックしました！'); await page.waitForTimeout(3000); await browser.close(); })();

📝 ポイント

クリック後は waitForTimeout() で少し待つと、結果を確認しやすいよ。

⚠️ クリックできない時は？

1. 要素が見つからない

// 存在するか確認してからクリック const button = page.getByText('送信'); if (await button.isVisible()) { await button.click(); }

2. 要素が画面外にある

// スクロールしてからクリック await page.getByText('もっと見る').scrollIntoViewIfNeeded(); await page.getByText('もっと見る').click();

3. 要素が読み込み中

// 表示されるまで待ってからクリック await page.getByText('送信').waitFor(); await page.getByText('送信').click();

🎯 このレッスンのまとめ

  • getByText() - テキストで要素を探してクリック
  • getByRole() - ボタンやリンクなど役割で探す
  • locator() - CSSセレクタで探す
  • dblclick() - ダブルクリック
  • hover() - マウスを乗せる
