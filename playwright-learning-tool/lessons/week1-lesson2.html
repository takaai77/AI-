Week 1 - レッスン 2/5

⚙️ Playwrightのしくみを理解しよう

ブラウザ・ページ・要素の関係を学ぼう！

🏗️ Playwrightの3つの階層

Playwrightでは、3つの大きな「箱」を使ってブラウザを操作します。

🌐 Browser
ブラウザ本体
↓ 中に
📄 Page
タブ（ページ）
📄 Page
タブ（ページ）
↓ 中に
🔘 Element
ボタンや入力欄
📝 Element
テキストや画像
  • Browser（ブラウザ） - ChromeやFirefoxのこと。一番大きな箱。
  • Page（ページ） - ブラウザのタブのこと。複数のタブを開ける。
  • Element（要素） - ボタン、入力欄、画像など、ページの中身。

📝 基本のコード構造

Playwrightのコードは、いつもこの形で始まります。

// ステップ1: Playwrightを読み込む const { chromium } = require('playwright'); // ステップ2: 処理を書く場所（おまじない） (async () => { // ステップ3: ブラウザを起動 const browser = await chromium.launch(); // ステップ4: 新しいページ（タブ）を開く const page = await browser.newPage(); // ─────────────────────────── // ここにやりたいことを書く！ // ─────────────────────────── // ステップ5: ブラウザを閉じる await browser.close(); })();

💡 覚えるポイント

この基本形は毎回使うので、コピペして使い回そう！
「async」と「await」は「待つ」という意味。ブラウザの処理が終わるまで待ってから次に進むよ。

🖥️ headless と headed

Playwrightは2つのモードでブラウザを動かせます。

headless: true
🙈 画面なし
速い！でも見えない
headless: false
👀 画面あり
遅いけど見える！
// 画面なし（デフォルト・高速） const browser = await chromium.launch(); // 画面あり（動きが見える・学習向き） const browser = await chromium.launch({ headless: false });

📝 おすすめ

学習中は headless: false にして、ブラウザの動きを目で確認しよう！

🎨 3つのブラウザエンジン

Playwrightは3種類のブラウザを動かせます。

  • chromium - Chromeと同じエンジン。一番よく使う。
  • firefox - Firefoxを動かす。
  • webkit - Safari（iPhoneのブラウザ）を動かす。
// Chrome系を使う（おすすめ） const { chromium } = require('playwright'); // Firefoxを使う const { firefox } = require('playwright'); // Safariを使う const { webkit } = require('playwright');

💡 使い分け

まずは chromium だけ使えばOK！慣れてきたら他も試してみよう。
