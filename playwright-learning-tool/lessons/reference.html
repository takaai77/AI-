📖 Playwright コマンド辞典

よく使うコマンドをすぐに調べられる！

🌐 ブラウザ操作

chromium.launch(options)
ブラウザを起動する
await chromium.launch({ headless: false })
browser.newPage()
新しいページ（タブ）を開く
const page = await browser.newPage()
browser.close()
ブラウザを閉じる
await browser.close()

🧭 ナビゲーション

page.goto(url)
指定URLに移動する
await page.goto('https://google.com')
page.goBack()
前のページに戻る
await page.goBack()
page.goForward()
次のページに進む
await page.goForward()
page.reload()
ページを更新する
await page.reload()
page.url()
現在のURLを取得
const currentUrl = page.url()
page.title()
ページタイトルを取得
const title = await page.title()

🎯 要素の検索（セレクタ）

page.getByRole(role, options) おすすめ
役割で要素を探す（button, link, textboxなど）
page.getByRole('button', { name: '送信' })
page.getByText(text) おすすめ
表示テキストで要素を探す
page.getByText('ログイン')
page.getByLabel(label)
ラベルで入力欄を探す
page.getByLabel('メールアドレス')
page.getByPlaceholder(text)
プレースホルダーで探す
page.getByPlaceholder('検索...')
page.locator(selector)
CSSセレクタで要素を探す
page.locator('#login-btn')
locator.first()
最初の要素を選択
page.locator('button').first()
locator.last()
最後の要素を選択
page.locator('button').last()
locator.nth(index)
N番目の要素を選択（0始まり）
page.locator('li').nth(2) // 3番目

🖱️ アクション

locator.click()
要素をクリック
await page.getByRole('button').click()
locator.dblclick()
ダブルクリック
await page.locator('#item').dblclick()
locator.fill(text)
テキストを入力（上書き）
await page.getByLabel('名前').fill('太郎')
locator.type(text)
1文字ずつ入力
await page.locator('input').type('hello')
locator.press(key)
キーを押す
await page.locator('input').press('Enter')
locator.clear()
入力欄をクリア
await page.locator('input').clear()
locator.check()
チェックボックスをチェック
await page.getByLabel('同意する').check()
locator.uncheck()
チェックを外す
await page.getByLabel('メール配信').uncheck()
locator.selectOption(value)
セレクトボックスで選択
await page.locator('select').selectOption('japan')
locator.hover()
マウスを乗せる
await page.getByText('メニュー').hover()

📊 情報取得

locator.textContent()
要素のテキストを取得
const text = await page.locator('h1').textContent()
locator.allTextContents()
全要素のテキストを配列で取得
const texts = await page.locator('li').allTextContents()
locator.getAttribute(name)
属性値を取得
const href = await page.locator('a').getAttribute('href')
locator.inputValue()
入力欄の値を取得
const value = await page.locator('input').inputValue()
locator.count()
要素の数を取得
const count = await page.locator('.item').count()
locator.isVisible()
表示されているか確認
const visible = await page.locator('#modal').isVisible()
locator.isEnabled()
有効（操作可能）か確認
const enabled = await page.locator('button').isEnabled()
locator.isChecked()
チェック状態を確認
const checked = await page.locator('input').isChecked()

⏳ 待機

page.waitForTimeout(ms)
指定ミリ秒待つ（デバッグ用）
await page.waitForTimeout(3000) // 3秒
locator.waitFor()
要素が表示されるまで待つ
await page.locator('#result').waitFor()
page.waitForLoadState(state)
ページ読み込み完了を待つ
await page.waitForLoadState('networkidle')
page.waitForURL(url)
URLが変わるまで待つ
await page.waitForURL('**/dashboard')

📸 スクリーンショット

page.screenshot(options)
ページのスクリーンショットを撮る
await page.screenshot({ path: 'screenshot.png' })
page.screenshot({ fullPage: true })
ページ全体を撮影
await page.screenshot({ path: 'full.png', fullPage: true })
locator.screenshot()
特定要素だけ撮影
await page.locator('#chart').screenshot({ path: 'chart.png' })
