Week 1 - レッスン 4/5

🧭 ページを移動しよう

前に戻る・進む・更新をマスター！

🚗 ナビゲーションコマンド

ブラウザで「戻る」「進む」「更新」ボタンを押すのと同じことが、コードでできます！

コマンド 説明 使う場面
page.goto(url) URLに移動 新しいページを開きたい時
page.goBack() 前のページに戻る 「戻る」ボタン
page.goForward() 次のページに進む 「進む」ボタン
page.reload() ページを更新 「F5」キー

📝 ナビゲーション実践コード

ファイル名: navigation.js

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); // 1. Googleにアクセス console.log('1️⃣ Googleにアクセス'); await page.goto('https://www.google.com'); await page.waitForTimeout(2000); // 2. Yahoo!に移動 console.log('2️⃣ Yahoo!に移動'); await page.goto('https://www.yahoo.co.jp'); await page.waitForTimeout(2000); // 3. 前のページ（Google）に戻る console.log('3️⃣ 前のページ（Google）に戻る'); await page.goBack(); await page.waitForTimeout(2000); // 4. 次のページ（Yahoo!）に進む console.log('4️⃣ 次のページ（Yahoo!）に進む'); await page.goForward(); await page.waitForTimeout(2000); // 5. ページを更新 console.log('5️⃣ ページを更新'); await page.reload(); await page.waitForTimeout(2000); console.log('✅ ナビゲーション完了！'); await browser.close(); })();

💡 ポイント

goBack() や goForward() は履歴がないと動きません。まず goto() で複数のページにアクセスしてから使おう！

📊 ページ情報を取得しよう

今いるページの情報も取得できます！

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch(); const page = await browser.newPage(); await page.goto('https://www.google.com'); // 現在のURL const url = page.url(); console.log('URL:', url); // ページのタイトル const title = await page.title(); console.log('タイトル:', title); await browser.close(); })();
コマンド 戻り値
page.url() 現在のURL（例: "https://www.google.com"）
page.title() ページのタイトル（例: "Google"）

📝 注意

url() は await 不要ですが、title() は await が必要です！

🔗 gotoのオプション

goto() にはいくつかのオプションがあります。

// 基本的な使い方 await page.goto('https://example.com'); // タイムアウトを設定（30秒） await page.goto('https://example.com', { timeout: 30000 }); // ページ読み込みの待機条件を指定 await page.goto('https://example.com', { waitUntil: 'networkidle' });
waitUntil の値 説明
'load' ページの読み込み完了（デフォルト）
'domcontentloaded' HTMLの読み込み完了（画像などは待たない）
'networkidle' ネットワーク通信が落ち着くまで待つ

🏋️ 練習問題

チャレンジ: サイト巡回プログラム

3つのサイトを順番に訪問して、各サイトのタイトルとURLを表示するプログラムを作ってみよう！

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); // 訪問するサイトのリスト const sites = [ 'https://www.google.com', 'https://www.yahoo.co.jp', 'https://www.youtube.com' ]; // 各サイトを訪問 for (const site of sites) { await page.goto(site); const title = await page.title(); const url = page.url(); console.log('━━━━━━━━━━━━━━━━━━━━'); console.log('📌 タイトル:', title); console.log('🔗 URL:', url); await page.waitForTimeout(2000); } console.log('━━━━━━━━━━━━━━━━━━━━'); console.log('✅ 巡回完了！'); await browser.close(); })();

🎯 このレッスンのまとめ

  • goto() - URLに移動
  • goBack() - 前のページへ
  • goForward() - 次のページへ
  • reload() - ページを更新
  • url() - 現在のURLを取得
  • title() - ページタイトルを取得
