Week 2 - レッスン 5/5

📋 フォーム自動入力

登録フォームを自動化しよう！

📝 フォーム要素の種類

要素操作方法
テキスト入力fill('テキスト')
チェックボックスcheck() / uncheck()
ラジオボタンcheck()
セレクトボックスselectOption('値')
ファイル選択setInputFiles('path')
送信ボタンclick()

☑️ チェックボックスとラジオボタン

// チェックボックスをチェック await page.getByLabel('利用規約に同意する').check(); // チェックを外す await page.getByLabel('メール配信を希望').uncheck(); // ラジオボタンを選択 await page.getByLabel('男性').check(); // チェック状態を確認 const isChecked = await page.getByLabel('利用規約').isChecked();

📋 セレクトボックス（ドロップダウン）

// 値（value）で選択 await page.locator('select#country').selectOption('japan'); // 表示テキスト（label）で選択 await page.locator('select#country').selectOption({ label: '日本' }); // インデックスで選択（0から始まる） await page.locator('select#month').selectOption({ index: 0 }); // 複数選択 await page.locator('select#skills').selectOption(['html', 'css', 'js']);

📁 ファイルアップロード

// 1つのファイルをアップロード await page.locator('input[type="file"]').setInputFiles('./photo.jpg'); // 複数ファイルをアップロード await page.locator('input[type="file"]').setInputFiles([ './doc1.pdf', './doc2.pdf' ]); // ファイル選択をクリア await page.locator('input[type="file"]').setInputFiles([]);

🎯 実践: 会員登録フォーム

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); // フォームページにアクセス await page.goto('https://example.com/register'); // テキスト入力 await page.getByLabel('お名前').fill('山田 太郎'); await page.getByLabel('メールアドレス').fill('taro@example.com'); await page.getByLabel('パスワード').fill('SecurePass123!'); // 生年月日（セレクト） await page.locator('select#year').selectOption('2010'); await page.locator('select#month').selectOption('4'); await page.locator('select#day').selectOption('15'); // 性別（ラジオ） await page.getByLabel('男性').check(); // 利用規約（チェックボックス） await page.getByLabel('利用規約に同意する').check(); // スクリーンショット await page.screenshot({ path: 'form-filled.png' }); console.log('✅ フォーム入力完了！'); await browser.close(); })();

🎯 Week 2 のまとめ

  • ✅ click() でボタンやリンクをクリック
  • ✅ fill() でテキストを入力
  • ✅ セレクタで要素を見つける方法
  • ✅ textContent() で情報を取得
  • ✅ check() / selectOption() でフォーム操作
