Week 3 - レッスン 1/5

⏳ 待機処理を理解しよう

ページの読み込みを待つ方法を学ぼう！

🤔 なぜ待機が必要？

Webページは一瞬で表示されるわけではありません。

  • 画像やデータの読み込みに時間がかかる
  • ボタンをクリックした後、結果が表示されるまで時間がかかる
  • ページの一部が後から表示される（Ajax）

Playwrightは自動的に待ってくれますが、手動で待機を指定することもできます。

⏰ 待機の種類

メソッド説明使う場面
waitForTimeout(ms)指定時間待つデバッグ・確認用
waitFor()要素が表示されるまで待つ動的コンテンツ
waitForLoadState()ページ読み込み完了を待つページ遷移後
waitForURL()URLが変わるまで待つリダイレクト
waitForResponse()API応答を待つデータ取得後

📝 基本的な待機

1. 固定時間待機（デバッグ用）

// 3秒待つ await page.waitForTimeout(3000);

⚠️ 注意

waitForTimeout は本番コードでは避けよう！実際の状態を待つ方が確実で速い。

2. 要素が表示されるまで待つ（おすすめ）

// 「ログイン成功」が表示されるまで待つ await page.getByText('ログイン成功').waitFor(); // 特定の状態を待つ await page.locator('#loading').waitFor({ state: 'hidden' });

3. ページ読み込み完了を待つ

// DOMの読み込み完了を待つ await page.waitForLoadState('domcontentloaded'); // ネットワーク通信が落ち着くまで待つ await page.waitForLoadState('networkidle');

4. URLが変わるまで待つ

// ログインボタンをクリック await page.getByRole('button', { name: 'ログイン' }).click(); // ダッシュボードページに遷移するまで待つ await page.waitForURL('**/dashboard');

🎯 実践例

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); await page.goto('https://example.com'); // ボタンをクリック await page.getByRole('button', { name: 'データを取得' }).click(); // ローディングが消えるまで待つ await page.locator('.loading-spinner').waitFor({ state: 'hidden' }); // 結果が表示されるまで待つ await page.locator('.results').waitFor(); // 結果を取得 const results = await page.locator('.results').textContent(); console.log('結果:', results); await browser.close(); })();

🎯 このレッスンのまとめ

  • waitFor() - 要素の表示を待つ（最もよく使う）
  • waitForLoadState() - ページ読み込みを待つ
  • waitForURL() - URL変更を待つ
  • waitForTimeout() - 固定時間待つ（デバッグ用）
