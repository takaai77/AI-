Week 1 - レッスン 1/5

🎮 プログラミングって何？

コンピュータに命令を出す魔法の言葉を学ぼう！

🤔 プログラミングってなんだろう？

プログラミングとは、コンピュータにやってほしいことを教えることです。

でも、コンピュータは人間の言葉がわかりません。だから、コンピュータがわかる特別な言葉（プログラミング言語）を使って、命令を書いていきます。

🍳

例え話：料理のレシピ

プログラミングは料理のレシピに似ています。

  • 「玉ねぎを切る」→「フライパンで炒める」→「塩を入れる」
  • 手順どおりにやれば、誰でも同じ料理ができる！

プログラミングも同じ。手順を書けば、コンピュータがその通りに動いてくれます！

🌐 ブラウザ自動化ってなに？

みんなは毎日インターネットを使っていますよね？

😫 手動でやると...

同じ作業を何度も繰り返し
時間がかかる
疲れる・ミスする

😎 自動化すると...

一度プログラムを書くだけ
あっという間に終わる
正確・ミスなし！

自動化できることの例

  • 🔍 たくさんのWebサイトから情報を集める
  • 📸 決まった時間にスクリーンショットを撮る
  • 📝 フォームに自動で入力する
  • ✅ Webサイトが正しく動くかテストする
  • 📊 データを集めてグラフにする

💡 身近な例

例えば、毎朝「今日の天気」を調べるのが面倒なら、自動で天気サイトにアクセスして情報を取得するプログラムが作れます！

🎭 Playwrightって何？

Playwright（プレイライト）は、ブラウザを自動で操作するための道具（ライブラリ）です。

📝 Playwrightの名前の由来

「Playwright」は英語で「劇作家」という意味。劇作家が役者に演技の指示を出すように、Playwrightはブラウザに動きの指示を出します！

Playwrightでできること

// こんなことができるよ！ // 1. ブラウザを開く ブラウザを起動する // 2. Webサイトにアクセス 「https://google.com」に移動する // 3. ボタンをクリック 「検索」ボタンをクリックする // 4. 文字を入力 検索ボックスに「Playwright」と入力する // 5. スクリーンショットを撮る 画面を撮影して保存する

✨ すごいところ

Playwrightは、Chrome、Firefox、Safariなど、いろんなブラウザを同じコードで動かせます！しかも無料で使えます。

🧪 実際のコードを見てみよう

これが実際のPlaywrightのコードです。まだ完全に理解できなくても大丈夫！雰囲気だけつかんでね。

// Playwrightを使う準備 const { chromium } = require('playwright'); // メインの処理 (async () => { // ブラウザを起動 const browser = await chromium.launch(); // 新しいページを開く const page = await browser.newPage(); // Googleにアクセス await page.goto('https://www.google.com'); // スクリーンショットを撮る await page.screenshot({ path: 'google.png' }); // ブラウザを閉じる await browser.close(); })();

💡 コードの読み方

// で始まる行はコメントです。コンピュータは無視するので、人間がメモを書くために使います。
