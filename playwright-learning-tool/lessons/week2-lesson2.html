🖊️ 入力のコード

方法1: fill() - 一番よく使う！

// 入力欄を見つけてテキストを入力 await page.locator('input[name="q"]').fill('Playwright 入門'); // プレースホルダーで見つけて入力 await page.getByPlaceholder('検索').fill('こんにちは'); // ラベルで見つけて入力 await page.getByLabel('ユーザー名').fill('taro');

💡 fill() の特徴

fill() は入力欄の中身を「一瞬で」置き換えます。すでに文字が入っていても、全部消して新しい文字を入れます。

方法2: type() - 1文字ずつ入力

// 人間が打つように1文字ずつ入力 await page.locator('input').type('こんにちは'); // 入力速度を指定（ミリ秒） await page.locator('input').type('ゆっくり入力', { delay: 100 });

方法3: pressSequentially() - 最新の方法

// 1文字ずつ順番に押す await page.locator('input').pressSequentially('hello');

🎹 特殊キーの入力

Enterキーやタブキーなど、特殊なキーも入力できます。

コード キー
press('Enter') Enterキー（決定・送信）
press('Tab') Tabキー（次の入力欄へ）
press('Escape') Escキー（キャンセル）
press('Backspace') バックスペース（1文字削除）
press('Control+a') Ctrl+A（全選択）
press('Control+c') Ctrl+C（コピー）
// 入力してEnterキーを押す await page.locator('input').fill('Playwright'); await page.locator('input').press('Enter'); // 全選択して削除 await page.locator('input').press('Control+a'); await page.locator('input').press('Backspace');

🔍 実践例: Google検索

const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const page = await browser.newPage(); // Googleにアクセス await page.goto('https://www.google.com'); // 検索ボックスに入力 await page.locator('input[name="q"]').fill('Playwright 使い方'); // Enterキーを押して検索 await page.locator('input[name="q"]').press('Enter'); // 結果を確認 await page.waitForTimeout(3000); console.log('✅ 検索完了！'); await browser.close(); })();

🧹 入力欄をクリアする

// 方法1: clear() を使う await page.locator('input').clear(); // 方法2: 空文字で fill() する await page.locator('input').fill(''); // 方法3: 全選択して削除 await page.locator('input').press('Control+a'); await page.locator('input').press('Backspace');
