Week 2 - レッスン 3/5

🎯 セレクタをマスター

要素を確実に見つける方法を学ぼう！

🔍 セレクタって何？

セレクタとは「Webページの中から特定の要素を見つける方法」です。

例えば、「赤いボタン」「ログインフォームの入力欄」「ページのタイトル」など、操作したい要素を指定するために使います。

<button id="login-btn" class="btn primary">ログイン</button>

この要素を見つけるには、いくつかの方法があります：

  • テキスト「ログイン」で探す
  • ID「login-btn」で探す
  • クラス「btn」で探す
  • ボタンという役割（role）で探す

⭐ おすすめのセレクタ（優先順位）

1位: getByRole() 最優先

要素の「役割」で見つける。一番信頼性が高い！

// ボタンを探す await page.getByRole('button', { name: '送信' }).click(); // リンクを探す await page.getByRole('link', { name: 'ホーム' }).click(); // テキストボックスを探す await page.getByRole('textbox', { name: 'メールアドレス' }).fill('test@example.com'); // チェックボックスを探す await page.getByRole('checkbox', { name: '利用規約に同意' }).check();
role対象要素
buttonボタン
linkリンク（a タグ）
textboxテキスト入力欄
checkboxチェックボックス
heading見出し（h1, h2...）
img画像

2位: getByText() おすすめ

画面に表示されているテキストで探す。

// 完全一致 await page.getByText('ログイン').click(); // 部分一致 await page.getByText('ログイン', { exact: false }).click();

3位: getByLabel() / getByPlaceholder() おすすめ

// ラベルで探す（フォーム向き） await page.getByLabel('ユーザー名').fill('taro'); // プレースホルダーで探す await page.getByPlaceholder('検索...').fill('Playwright');

4位: locator() - CSSセレクタ 必要な時だけ

// IDで探す（#をつける） await page.locator('#submit-button').click(); // クラスで探す（.をつける） await page.locator('.login-form').click(); // 属性で探す await page.locator('input[name="email"]').fill('test@example.com'); // 複合セレクタ await page.locator('div.container button.primary').click();

🔗 セレクタを組み合わせる

// 特定のエリア内の要素を探す await page.locator('.login-form').getByRole('button').click(); // 最初の要素だけ await page.getByRole('button').first().click(); // 最後の要素 await page.getByRole('button').last().click(); // N番目の要素（0から始まる） await page.getByRole('button').nth(2).click(); // 3番目

🎯 このレッスンのまとめ

  • getByRole() - 役割で探す（最優先）
  • getByText() - テキストで探す
  • getByLabel() - ラベルで探す
  • getByPlaceholder() - プレースホルダーで探す
  • locator() - CSSセレクタで探す
  • first() / last() / nth() - 複数ある時に絞り込む
