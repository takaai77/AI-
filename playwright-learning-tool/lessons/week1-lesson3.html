Week 1 - レッスン 3/5

🚀 ブラウザを操作してみよう

実際にコードを動かしてみよう！

📁 プロジェクトを作ろう

まずは作業用のフォルダを作って、Playwrightをインストールしよう！

ステップ1: フォルダを作成

# デスクトップに移動（Windowsの場合） cd Desktop # 新しいフォルダを作成 mkdir playwright-practice # フォルダに移動 cd playwright-practice

ステップ2: プロジェクトを初期化

# package.jsonを作成（-y で全部デフォルト設定） npm init -y

ステップ3: Playwrightをインストール

# Playwrightをインストール npm install playwright

💡 時間がかかるよ

Playwrightのインストールには数分かかることがあります。ブラウザのダウンロードも一緒に行われるからです。

📝 はじめてのスクリプト

新しいファイルを作って、以下のコードを書いてみよう！

ファイル名: first-script.js

// Playwrightを読み込む const { chromium } = require('playwright'); (async () => { console.log('🚀 ブラウザを起動します...'); // ブラウザを起動（画面を表示する） const browser = await chromium.launch({ headless: false }); console.log('📄 新しいページを開きます...'); // 新しいページを開く const page = await browser.newPage(); console.log('🌐 Googleにアクセスします...'); // Googleにアクセス await page.goto('https://www.google.com'); console.log('⏳ 5秒待ちます（画面を確認してね）...'); // 5秒待つ await page.waitForTimeout(5000); console.log('👋 ブラウザを閉じます...'); // ブラウザを閉じる await browser.close(); console.log('🎉 完了！お疲れさま！'); })();

実行してみよう！

node first-script.js

✨ 成功したかな？

ブラウザが自動で開いて、Googleが表示されたら大成功！

🔧 コードの解説

1. require（読み込み）

const { chromium } = require('playwright');

Playwrightの中から chromium（Chrome系ブラウザ）を使う準備。

2. launch（起動）

const browser = await chromium.launch({ headless: false });

ブラウザを起動。headless: false で画面を表示。

3. newPage（新しいページ）

const page = await browser.newPage();

新しいタブを開く。

4. goto（移動）

await page.goto('https://www.google.com');

指定したURLにアクセス。

5. waitForTimeout（待機）

await page.waitForTimeout(5000);

5000ミリ秒（5秒）待つ。結果を確認する時間を作れる。

6. close（終了）

await browser.close();

ブラウザを閉じる。これを忘れるとブラウザが残っちゃう！

🏋️ 練習問題

チャレンジ1: 別のサイトにアクセスしてみよう

Googleの代わりに、以下のサイトにアクセスするコードに書き換えてみよう：

  • Yahoo! Japan: https://www.yahoo.co.jp
  • YouTube: https://www.youtube.com
  • Wikipedia: https://ja.wikipedia.org

チャレンジ2: 待ち時間を変えてみよう

waitForTimeout の数値を変えて、待ち時間を変更してみよう：

  • 1秒 = 1000
  • 3秒 = 3000
  • 10秒 = 10000

チャレンジ3: 複数のサイトにアクセス

goto を複数回使って、いくつかのサイトを順番に見てみよう！

await page.goto('https://www.google.com'); await page.waitForTimeout(2000); await page.goto('https://www.yahoo.co.jp'); await page.waitForTimeout(2000); await page.goto('https://www.youtube.com'); await page.waitForTimeout(2000);

⚠️ よくあるエラーと対処法

エラー: Cannot find module 'playwright'

Playwrightがインストールされていない。npm install playwright を実行しよう。

エラー: Navigation timeout

ネットワークが遅いか、サイトが重い。待ち時間を長くするか、ネット接続を確認しよう。

エラー: Protocol error

ブラウザが予期せず閉じた。コードを確認して再実行しよう。

  • npm init -y でプロジェクトを初期化
  • npm install playwright でインストール
  • launch() でブラウザを起動
  • goto() でURLに移動
  • waitForTimeout() で待機
  • close() でブラウザを閉じる
