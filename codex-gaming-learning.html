MISSION 1: Codexとは何か？

ようこそ、新人エージェント。君はこれからCodexという強力なAIツールを習得する旅に出る。

Codexの正体

Codexとは、自然言語をプログラミングコードに変換できるAIシステムだ。人間の言葉で指示を出すと、それを理解してコードを生成してくれる。

PRO TIP

Codexは「コードを書く」だけでなく、「コードを理解する」「バグを見つける」「最適化する」など、様々なタスクをこなせる。

主な能力

  • コード生成 - 自然言語の説明からコードを作成
  • コード補完 - 途中のコードを予測して完成
  • コード翻訳 - ある言語から別の言語へ変換
  • デバッグ支援 - エラーの原因を特定し修正案を提示
# 例: Codexへの指示
USER: "配列の中から最大値を見つける関数を作って"

CODEX:
function findMax(arr) {
  return Math.max(...arr);
}

MISSION 2: 効果的なプロンプトの書き方

Codexを最大限に活用するには、正確で明確なプロンプトを書くスキルが必要だ。

プロンプトの黄金律

  • 具体的に - 曖昧な指示は曖昧な結果を生む
  • 文脈を与える - 何のためのコードか説明する
  • 例を示す - 入出力の例があると精度が上がる
  • 制約を明記 - 言語、ライブラリ、スタイルを指定
BAD vs GOOD プロンプト

GOOD: "Pythonで数値のリストを降順にソートする関数を作成してください。組み込み関数を使わず、クイックソートアルゴリズムで実装してください。"

MISSION 4: デバッグの極意

Codexはデバッグの強力な味方になる。バグを見つけ、修正する方法を学ぼう。

バグ特定の依頼方法

USER:
以下のコードにバグがあります。見つけて修正してください:

function calculateAverage(numbers) {
  let sum = 0;
  for (let i = 0; i <= numbers.length; i++) {
    sum += numbers[i];
  }
  return sum / numbers.length;
}

CODEX:
バグ発見: ループ条件が i <= numbers.length になっています。
これにより配列外アクセスが発生します。
修正: i < numbers.length に変更してください。

エラーメッセージの解析

DEBUG STRATEGY

エラーメッセージと関連するコードを一緒にCodexに渡すと、的確な診断が得られる。スタックトレースも含めるとさらに精度アップ！
