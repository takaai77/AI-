## このツールは何をするの？

### 🎯 一言で言うと

**「動画を見せると、その動画の内容をAIが理解して、画像を作るための『レシピ（プロンプト）』を自動で書いてくれるツール」**です。

### 📖 もう少し詳しく

例えば、YouTubeで見つけた素敵な動画があるとします。その動画の雰囲気や構図を参考にして、MidjourneyやStable Diffusionといった「AI画像生成ツール」で似た画像を作りたいとしましょう。

通常、AI画像生成ツールを使うには、「どんな画像を作りたいか」を文章で細かく説明する必要があります。これを**「プロンプト」**と呼びます。

しかし、動画を見ながら「どう説明すればいいか」を考えるのは大変です。

そこでこのツールの出番！

1. 動画のURL（またはファイル）を渡す
2. AIが動画を**見て**、内容を理解する
3. **（オプション）AIが動画を「聞いて」、セリフやBGMも分析する**
4. 「こんな感じで説明すればいいよ」というプロンプトを自動生成
5. そのプロンプトをコピーして、Midjourneyなどで使う

これで、動画の雰囲気を再現した画像を簡単に作れるようになります！

**🆕 音声分析機能（NEW!）**
このツールは、動画の「映像」だけでなく、**「音声」**も分析できます！
- セリフや会話の文字起こし
- BGM（背景音楽）の雰囲気やテンポの分析
- これらの情報をプロンプトに反映して、より雰囲気のある画像生成が可能に

## どんな時に使えるの？

### ✨ 使用シーン例

#### 1. **SNSで見つけた動画の雰囲気を再現したい**
Xや Instagramで「この動画の雰囲気いいな！」と思ったら、URLをこのツールに入れるだけ。同じ雰囲気の画像を作るためのプロンプトが手に入ります。

#### 2. **YouTube動画から複数のアイデアを抽出**
長めのYouTube動画から、複数のシーンを自動で検出して、それぞれのシーンに対応したプロンプトを生成できます。

#### 3. **ローカルに保存した動画も処理可能**
スマホで撮影した動画や、パソコンに保存してある動画ファイルも使えます。

#### 4. **画像生成AIの練習に**
「どうプロンプトを書けばいいか分からない」という初心者の方にも、AIが生成したプロンプトを見て学べます。

## 仕組みを分かりやすく解説

### 🔄 処理の流れ（全体像）

```
動画URL
  ↓
【ステップ1】動画をダウンロード
  ↓
【ステップ2】動画をAIに送る
  ↓
【ステップ3】AIが動画を分析
  ↓
【ステップ4】プロンプトを生成
  ↓
結果を保存（JSON形式）
```

### 📝 各ステップの詳細

#### **ステップ1: 動画をダウンロード**

**何をしているの？**
- YouTubeやXなどの動画URLから、動画ファイルをパソコンにダウンロードします
- ローカルファイルの場合は、そのまま使います

**例えで言うと**
- 図書館から本を借りてくるイメージ
- オンラインにある動画を、手元で扱えるようにする作業です

**使う技術:**
- **pytube**: YouTube専用の高速ダウンローダー
- **yt-dlp**: YouTube以外の1000以上のサイトに対応した万能ダウンローダー

---

#### **ステップ2: 動画をAIに送る**

**何をしているの？**
- ダウンロードした動画を、GoogleのAI（Gemini）に送ります
- AIが動画を見られる状態にします

**例えで言うと**
- 友達に「この動画見て！」とファイルを送るイメージ
- AIが動画を「視聴」できるように準備する作業です

**使う技術:**
- **Google Gemini API**: Googleが提供する動画・画像を理解できるAI

---

#### **ステップ3: AIが動画を分析**

**何をしているの？**
- AIが動画を見て、以下のことを理解します：
  - 何が映っているか（人、風景、物など）
  - どんな雰囲気か（明るい、暗い、カラフルなど）
  - どんな構図か（真正面、斜め上から、など）
  - どんなスタイルか（写真風、イラスト風、アニメ風など）

**例えで言うと**
- プロのカメラマンが動画を見て、「この映像のポイントはこれですね」と分析するイメージ
- AIが「人間の目」の代わりに動画を見て、特徴を把握します

**オプション機能:**
- **カット割り検出**: 動画のシーンが切り替わるタイミングを自動検出
  - 例: 1分の動画で3回シーンが変わったら、3つのプロンプトを作る
- **フレーム抽出**: 各シーンの代表的な1枚の画像を保存

---

#### **ステップ4: プロンプトを生成**

**何をしているの？**
- AIが理解した内容を元に、画像生成AIで使えるプロンプト（説明文）を作ります
- 英語と日本語の両方で生成されます

**例えで言うと**
- 料理のレシピを書くイメージ
- 「どんな材料（要素）を、どう組み合わせれば、この雰囲気が再現できるか」を文章にします

**プロンプトの例:**

動画: 夕暮れの海辺を歩く人
```
英語プロンプト:
cinematic beach sunset scene, silhouette of person walking,
golden hour lighting, warm orange and purple sky,
calm ocean waves, peaceful atmosphere, high quality,
8k resolution, professional photography

日本語説明:
映画的な夕暮れのビーチシーン、歩く人のシルエット、
ゴールデンアワーの照明、暖かいオレンジと紫の空、
穏やかな海の波、平和な雰囲気
```

## 使われている技術を例えで説明

### 🤖 Google Gemini API

**何ができる？**
- 動画や画像を「見て」理解できるAI

**例えで言うと**
- とても賢いアシスタント
- 動画を見せると「これは夕焼けの海辺で、人が歩いていますね」と説明してくれる
- 人間の目と脳の代わりをしてくれるイメージ

**この技術のすごいところ:**
- 動画の内容を本当に「理解」できる
- 単なる色や形の認識だけでなく、「雰囲気」や「スタイル」も理解する

---

### 📥 yt-dlp（ワイティー・ディーエルピー）

**何ができる？**
- 1000以上のサイトから動画をダウンロードできるツール

**例えで言うと**
- インターネット上の動画専用のコピー機
- YouTube、X（Twitter）、Instagram、TikTokなど、様々なサイトの動画を手元に保存できる

**対応サイト:**
- YouTube
- X（旧Twitter）
- Instagram
- TikTok
- Vimeo
- その他1000以上のサイト

---

### 🎬 OpenCV（オープンシーブイ）

**何ができる？**
- 動画や画像を処理するためのツール
- このプロジェクトでは「カット割り検出」に使用

**例えで言うと**
- 動画の「目利き」
- 動画を1コマずつ見て、「あ、ここでシーンが変わった！」と教えてくれる

**カット割り検出の仕組み:**
動画は1秒間に30枚などの「写真（フレーム）」が連続して表示されることで動いて見えます。
OpenCVは、その写真を1枚ずつ比較して：
1. 色の分布を調べる
2. 前の写真と大きく変わったら「シーンが変わった！」と判断
3. その時間を記録

**例:**
```
0:00 - 0:15 → オープニング（海辺の風景）
0:15 - 0:45 → 人が歩くシーン
0:45 - 1:00 → クローズアップ（顔のアップ）
```

それぞれのシーンに対して、別々のプロンプトを生成できます。

---

### 🎤 OpenAI Whisper（ウィスパー）

**何ができる？**
- 動画の音声を「聞いて」、セリフや会話を文字に起こすツール

**例えで言うと**
- とても賢い「文字起こし専門の秘書」
- 動画を再生すると、話している内容を正確にメモしてくれる
- 日本語、英語など多言語に対応

**この技術のすごいところ:**
- 人間レベルの精度で音声を認識
- タイムスタンプ付き（「いつ、何を言ったか」が分かる）
- 雑音があっても比較的正確に認識できる

**使用例:**
動画内で「こんにちは、今日は素晴らしい天気ですね」と言っているシーンがあれば、
Whisperが「`[00:00:05] こんにちは、今日は素晴らしい天気ですね`」と文字起こししてくれます。
これをプロンプトに含めることで、**「挨拶のシーン」** や **「明るい雰囲気」** などを AI画像生成に反映できます。

---

### 🎵 librosa（リブローサ）

**何ができる？**
- 音楽やBGMを「聞いて」、その特徴を分析するツール

**例えで言うと**
- 音楽の「プロの評論家」
- BGMを聞いて、「これはテンポが速い、エネルギッシュな曲だね」と教えてくれる

**分析できる情報:**
- **テンポ（BPM）**: 曲の速さ（例: 120 BPM = 1分間に120拍）
- **雰囲気**: 明るい、暗い、穏やか、激しい など
- **エネルギーレベル**: 静かな曲か、激しい曲か
- **キー（音階）**: C、D、E# など

**使用例:**
動画のBGMが「テンポ: 140 BPM、雰囲気: upbeat/exciting、エネルギー: 0.85」だと分析されたら、
プロンプトに **「dynamic, energetic atmosphere, fast-paced」** などの表現を追加できます。
これにより、BGMの雰囲気に合った画像を生成できます。

---

### 🌐 Streamlit（ストリームリット）

**何ができる？**
- PythonのプログラムをWebサイト風の見た目にできるツール

**例えで言うと**
- 「プログラムの着せ替え」
- 難しいコマンドを打たなくても、ボタンをクリックするだけで使える

**このツールでの役割:**
- iPhoneやスマホのブラウザから使えるようにする
- ファイルのアップロードや結果の表示を、見やすく操作しやすくする

**特徴:**
- モバイル対応（iPhone、Android対応）
- 直感的な操作（ボタンクリックだけ）
- リアルタイムで進捗が見える

---

### 🔒 .env（ドットエンブ）ファイル

**何のため？**
- APIキー（秘密の鍵）を安全に保存するファイル

**例えで言うと**
- 金庫に入れる暗証番号のメモ
- 他人に見られてはいけない重要情報を保管する場所

**なぜ必要？**
Google Gemini APIを使うには、「APIキー」という特別なパスワードが必要です。
これをプログラムに直接書くと、GitHubなどに公開した時に他人に見られて悪用される危険があります。

そこで、`.env`ファイルに書いておけば：
- `.gitignore`で自動的にGitHubにアップロードされない
- 自分のパソコンだけに保存される

---

### 📦 JSON（ジェイソン）形式

**何これ？**
- データを保存するための「形式」の1つ

**例えで言うと**
- 整理整頓された箱
- 「名前」と「中身」がセットになって保存されている

**JSON の例:**
```json
{
  "動画URL": "https://youtube.com/watch?v=example",
  "要約": "夕暮れの海辺を歩く人の動画",
  "プロンプト数": 3,
  "プロンプト一覧": [
    {
      "シーン": 1,
      "時間": "00:00:00",
      "説明": "オープニング",
      "プロンプト": "beach sunset scene..."
    }
  ]
}
```

**なぜJSON？**
- 人間にも読みやすい
- プログラムでも処理しやすい
- 様々なツールで使える

## iPhoneから使う方法

### 📱 ステップ・バイ・ステップ

#### **準備（初回のみ）**

1. **パソコンでプロジェクトをセットアップ**
   ```bash
   # 必要なツールをインストール
   pip install -r requirements.txt

   # APIキーを設定（.envファイル）
   GOOGLE_API_KEY=your_api_key_here
   ```

2. **Webサーバーを起動**
   ```bash
   streamlit run web_ui.py
   ```

3. **表示されたアドレスを確認**
   ```
   Local URL: http://localhost:8501
   Network URL: http://192.168.1.100:8501
   ```

---

#### **iPhoneでアクセス**

1. **同じWi-Fiに接続**
   - パソコンとiPhoneを同じWi-Fiに接続します
   - 例: 両方とも自宅のWi-Fi「MyHome」に接続

2. **iPhoneのSafariを開く**
   - Safariアプリを起動

3. **Network URLにアクセス**
   - 先ほど表示された `Network URL` をブラウザに入力
   - 例: `http://192.168.1.100:8501`

4. **Webページが表示されます！**
   - これでiPhoneから使えます 🎉

---

#### **使い方（iPhone）**

##### 📌 方法1: URL入力

1. **「URL入力」タブを選択**
2. **動画のURLを入力**
   - YouTube、X、Instagramなどの動画URL
   - 例: `https://youtube.com/watch?v=abc123`
3. **サイドバーで設定**
   - プロンプト言語: 日本語 / 英語
   - カット割り検出: ON / OFF
   - フレーム抽出: ON / OFF
   - **🆕 音声分析: ON / OFF（セリフとBGMを分析）**
   - 音声認識モデル: tiny〜medium（精度を選択）
4. **「🚀 プロンプトを生成」ボタンをタップ**
5. **待つ（音声分析ONの場合は2〜5分程度）**
6. **結果が表示されます！**

##### 📌 方法2: ファイルアップロード

1. **「ファイルアップロード」タブを選択**
2. **「ファイルを選択」をタップ**
3. **iPhoneの動画を選択**
   - カメラロールから選べます
4. **あとは方法1と同じ**

---

#### **結果の活用**

##### ✅ プロンプトをコピー
各シーンのプロンプトの下に「📋 プロンプトをコピー」ボタンがあります。
タップすると、クリップボードにコピーされるので、そのままMidjourneyなどに貼り付けできます。

##### ✅ 結果をダウンロード
- **JSON形式**: プログラムで再利用する場合
- **テキスト形式**: 読みやすい形式で保存

##### ✅ フレーム画像を確認
シーン検出を有効にした場合、各シーンの代表画像が表示されます。
これを見ながら「どのシーンのプロンプトを使うか」を選べます。

## よくある質問

### ❓ どのくらいの長さの動画まで処理できる？

**回答:**
技術的には数分〜10分程度の動画が最適です。

**理由:**
- APIのアップロード制限（500MB以下推奨）
- 処理時間（長い動画ほど時間がかかる）

**おすすめ:**
- 30秒〜3分程度の動画
- それ以上長い場合は、事前に必要な部分だけ切り出す

---

### ❓ プロンプトの精度はどのくらい？

**回答:**
かなり高精度ですが、完璧ではありません。

**特徴:**
- ✅ 視覚的な要素（色、構図、雰囲気）は非常に正確
- ✅ 具体的なオブジェクト（人、物、風景）も正確
- ⚠️ 抽象的な概念や複雑なストーリーは、やや簡略化される

**使い方のコツ:**
- 生成されたプロンプトをそのまま使うのも良い
- さらに自分で微調整すると、より理想に近づく

---

### ❓ X（Twitter）の全ての動画が使える？

**回答:**
ほとんどの動画は使えますが、一部制限があります。

**使える:**
- ✅ 公開アカウントの動画
- ✅ 通常のツイートの動画

**使えない可能性:**
- ❌ 非公開アカウント（鍵アカウント）の動画
- ❌ 削除されたツイート
- ❌ 年齢制限のある動画

---

### ❓ APIキーって何？どうやって取得する？

**回答:**
APIキーは、GoogleのAIを使うための「許可証」のようなものです。

**取得方法:**

1. **Google AI Studioにアクセス**
   - https://makersuite.google.com/app/apikey

2. **Googleアカウントでログイン**

3. **「Create API Key」をクリック**

4. **生成されたキーをコピー**
   - 例: `AIzaSyABC123...`（長い文字列）

5. **.envファイルに貼り付け**
   ```
   GOOGLE_API_KEY=AIzaSyABC123...
   ```

**注意:**
- APIキーは絶対に他人に見せない
- GitHubなどに公開しない
- `.env`ファイルは`.gitignore`に含まれているので安全

---

### ❓ APIの料金は？

**回答:**
Google Gemini APIには無料枠があります。

**無料枠（2025年1月時点）:**
- 月に一定回数まで無料
- 個人利用なら無料枠内で十分使える

**有料プラン:**
- 無料枠を超えた場合に課金
- 使った分だけ支払う従量課金制

**目安:**
1本の動画処理で、数円〜数十円程度（動画の長さによる）

---

### ❓ iPhoneから使えない場合は？

**チェックリスト:**

1. **パソコンとiPhoneが同じWi-Fiに接続されているか？**
   - 設定アプリで確認

2. **正しいURLを入力しているか？**
   - `Network URL`を使う（`Local URL`ではない）
   - 例: `http://192.168.1.100:8501`

3. **パソコンのファイアウォールで遮断されていないか？**
   - Windowsの場合、ファイアウォール設定を確認
   - Macの場合、システム設定 > ネットワーク > ファイアウォール

4. **Streamlitが起動しているか？**
   - パソコンのターミナルで確認
   - `streamlit run web_ui.py`が実行中か確認

### ❓ エラーが出た時は？

**よくあるエラーと対処法:**

#### **1. "GOOGLE_API_KEY not found"**
**原因:** APIキーが設定されていない
**対処法:** `.env`ファイルにAPIキーを設定

#### **2. "Failed to download video"**
**原因:**
- 動画URLが間違っている
- 動画が削除されている
- ネットワークエラー

**対処法:**
- URLを確認
- 別の動画で試す
- インターネット接続を確認

#### **3. "API rate limit exceeded"**
**原因:** APIの無料枠を使い切った
**対処法:**
- 時間をおいて再試行（翌日など）
- 有料プランを検討

## 🎓 まとめ

このツールは、**動画からAI画像生成のプロンプトを自動作成**する便利なツールです。

**特徴:**
- ✅ YouTube、X、Instagramなど多数のプラットフォームに対応
- ✅ ローカルファイルも処理可能
- ✅ シーン検出で複数のプロンプトを一度に生成

- **API**: サービスを使うための窓口

- **JSON**: データを整理して保存する形式
